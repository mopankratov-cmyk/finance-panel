# Финансы МП — панель управления маркетплейсами

Панель для продавца **Wildberries + Ozon**: аналитика, финансы и операции в одном месте. Все цифры считаются на реальных данных кабинетов (WB/Ozon API + Supabase) на цене **до СПП**, с фактической комиссией и удержаниями — без «наценок» маркетплейса поверх.

> Контент-завод (генерация видео/фото, UGC-блогеры) вынесен в отдельный репозиторий **content-factory**. Здесь — только управление маркетплейсами и финансы.

## Что внутри

**📊 Аналитика МП**
- **Реклама WB** (`/adverts`) — активные РК, расход по SKU, ДРР, баланс продвижения
- **РНП по SKU** (`/rnp`) — заказы/выкупы/реклама/ДРР/маржа/GMROI, окно 7/14/30д
- **SEO / Воронка** (`/seo`) — показы → CTR → корзина → заказ
- **Склейки** (`/sklejki`) — объединённые карточки по imtID
- **Юнит-экономика** (`/unit`) — прибыль/ед: цена до СПП минус все расходы МП
- **CTR по SKU** (`/ctrtest`) — CTR/CPC/ДРР рекламы
- **Планирование** (`/planning`) — годовой план заказов и остатки
- **Ozon Аналитика** (`/ozon`), **ABC прибыли** (`/abc`), **Динамика** (`/trends`), **Рынок** (`/market`, MPSTATS)

**💰 Финрезультат и деньги**
- **ОПиУ / P&L** (`/pnl`, `/opiu`) — понедельный P&L WB+Ozon до СПП + соинвест
- **Где теряем** (`/losses`), **Сводка** (`/summary`) — удержания по статьям
- **Календарь ДДС** (`/calendar`), **Платежи** (`/payments`, импорт из Google-таблицы), **Кредиты** (`/loans`), **Счета** (`/accounts`)

**⚙️ Операции**
- **Закупки** (`/supplies`), **Себестоимость** (`/costs`), **Репрайсер** (`/repricer`), **Решатель цены** (`/price-solver`), **Синхронизация** (`/sync`)

**🔐 Платформа**
- **Кабинеты** (`/cabinets`) — подключение WB/Ozon по токену со скоуп-пробой
- **Сотрудники** (`/users`) — роли director / finance / manager (RBAC)
- **AI-агент** (`/agent`) — чат по данным WB + движок инсайтов «что требует внимания»

## Стек

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind · Supabase (Postgres) · JWT/bcrypt-авторизация · Recharts. Деплой — Vercel (`finance-panel-two.vercel.app`).

## Разработка

```bash
npm install
npm run dev        # http://localhost:3000
```

Нужен `.env.local` с ключами Supabase и токенами кабинетов (см. владельца — секреты не в репозитории). Перед PR:

```bash
npx tsc --noEmit   # типы
npm run build      # сборка
```
