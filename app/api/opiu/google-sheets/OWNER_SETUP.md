# Подключение финансовой панели к Google Таблице

1. Создайте одну Google Таблицу для финансов или откройте существующую.
2. Скопируйте ID из адреса: `https://docs.google.com/spreadsheets/d/ЭТОТ_ID/edit`.
3. В таблице откройте **Расширения → Apps Script**.
4. Замените содержимое `Code.gs` кодом из файла `GoogleAppsScript.gs` рядом с этой инструкцией.
5. В Apps Script откройте **Настройки проекта → Свойства скрипта** и добавьте:
   - `FINANCE_SPREADSHEET_ID` — ID таблицы;
   - `FINANCE_SYNC_SECRET` — длинный случайный секрет.
6. Нажмите **Развернуть → Новое развертывание → Веб-приложение**.
7. «Выполнять от имени»: **Я**. «У кого есть доступ»: **Все**.
8. Скопируйте URL развертывания вида `https://script.google.com/macros/s/.../exec`.
9. На сервере панели задайте:
   - `FINANCE_GOOGLE_SHEETS_WEBHOOK_URL` — URL из пункта 8;
   - `FINANCE_GOOGLE_SHEETS_SECRET` — тот же секрет из пункта 5.
10. В целевой книге заранее должны находиться исходные листы-шаблоны. Скрипт больше не создаёт упрощённые листы: если шаблон не найден, он остановит выгрузку с понятной ошибкой.
11. Перезапустите приложение и сначала проверьте выгрузку одного небольшого периода.

Скрипт продолжает существующие листы `ДДС месяц`, `Плановый Реестр поступлений`, `План выбытий РИО`, `Факт ДДС` и `Учёт кредитов займов от сторонн`. Он находит настоящую строку заголовков, копирует оформление и формулы предыдущей строки, заполняет только исходные поля и проверяет дубли по дате, сумме и основным реквизитам операции.
