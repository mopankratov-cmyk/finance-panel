# Handoff: НОДА/studio — нод-студия виральных видео

## Overview
Профессиональный десктоп-инструмент, которым селлер маркетплейса (Wildberries / Ozon) собирает короткие вертикальные видео (TikTok / Reels) для карточек товаров. Видео собирается как **граф типизированных нод** (`HOOK + SCENE×N + PAYOFF + CAPTIONS + MUSIC + EFFECTS`); на каждую ноду навешивается инструмент-генератор (AI-видео Seedance, UGC-актёр Creatify, монтаж/титры Shotstack и т.д.) со всеми его API-настройками. Единственный пользователь — сам владелец-эксперт. Интерфейс русский, тёмная тема первична.

Философия: **«настраиваемо под капотом, просто сверху»** — все настройки открыты и сгруппированы (не спрятаны за тумблерами), но организованы так, чтобы не превращаться в стену. Уровень плотности и мощи — ComfyUI / Linear / Figma, НЕ упрощённый мастер для новичка.

## About the Design Files
Файлы в этом пакете — **дизайн-референсы, сделанные в HTML**. Это прототип, показывающий задуманный вид и поведение, **а не продакшн-код для прямого копирования**. Задача — **воссоздать эти экраны в среде целевого кодовой базы** (React, Vue, и т.д.), используя её устоявшиеся паттерны, компоненты и библиотеки. Если среды ещё нет — выбрать наиболее подходящий фреймворк (рекомендация: **React + TypeScript**, для канваса — React Flow / @xyflow/react, для стилей — CSS-модули или Tailwind с токенами ниже) и реализовать там.

Источник: единый Design Component `Нод-студия.dc.html`. Это формат streaming-компонента с инлайновыми стилями; **не тащите в продакшн рантайм `support.js` / `data-dc-*` атрибуты** — берите из файла разметку, размеры, цвета и копирайт, а структуру стройте на компонентах своего кода.

## Fidelity
**High-fidelity (hifi).** Финальные цвета, типографика, отступы, состояния и интеракции. Воссоздавать UI пиксель-в-пиксель, подставляя компоненты своей дизайн-системы. Все hex-значения, размеры и копирайт — точные (см. Design Tokens).

## Interactions & Behavior
- **Навигация**: клик по пункту рейла → меняет `screen`. Табы инструментов в инспекторе → меняют `tool` (seedance/creatify/shotstack), перерисовывая группы полей и цену.
- **Канвас**: drag-drop нод из палитры; соединение портов перетаскиванием — **запрет на несовместимые типы** (цвет = тип); зум/пан; авто-укладка; минимап.
- **Группы инспектора**: сворачиваются/разворачиваются (визуальная организация, не сокрытие — дефолт развёрнуто).
- **Генерация**: кнопка «▶ Превью» → состояние generating (спиннер + прогресс % + текущая цена) → ready (превью + балл ОТК) или error (текст + «Повторить»).
- **Сборка**: «Смонтировать» собирает таймлайн → ОТК считает 5 осей и вердикт.
- **Анимации**: `spin .8s linear infinite` (спиннеры), `pulseDot 1s` (статус-точка генерации), `shimmer 1.4s` (скелетоны), `dash 1s linear infinite` (активная audio-связь).

## State Management
- `screen`: `'center' | 'compete' | 'canvas' | 'inspector' | 'assembly' | 'library' | 'ds'`.
- `tool` (инспектор): `'seedance' | 'creatify' | 'shotstack'` → производные `priceVal/priceFormula/priceTitle/priceDot`.
- Прод-состояние (расширить): граф (ноды + связи + позиции + статусы + баллы ОТК), выбранная нода, значения настроек на ноду, очередь генераций/прогресс, версии графа (дерево форков), агрегаты стоимости. Данные генераций — через API инструментов (Seedance/Creatify/Shotstack); статусы рендеров — поллинг/вебсокеты.
