# Переменные окружения

Что нужно положить в `.env.local`, чтобы панель заработала локально.

Файл владелец присылает целиком через 1Password или Bitwarden Send. Этот
документ — чтобы обе стороны видели один список: владелец не забыл ключ, а
разработчик понимал, почему раздел не работает.

> Здесь только имена. Значений в репозитории нет и не будет.
> `.env.local` лежит в `.gitignore` — так и оставь.

## Без этого не поднимется

| Переменная | Зачем |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | адрес базы |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | публичный ключ для клиента |
| `SUPABASE_SERVICE_ROLE_KEY` | серверный ключ; **без него панель стартует, но все экраны пустые** — роуты не получают доступа к данным |
| `AUTH_SECRET` | подпись сессии. Если не задать, код возьмёт заглушку из исходников: для локальной разработки терпимо, для общего стенда — нет |

## Маркетплейсы

Токены кабинетов WB и Ozon хранятся **в базе**, а не в окружении: их заводит
владелец через раздел «Кабинеты». Отдельных переменных для них не нужно.

| Переменная | Зачем |
|---|---|
| `MPSTATS_TOKEN` | внешняя аналитика; нужна разделам «Рынок» и «Ниши» |

## Фоновые прогоны

| Переменная | Зачем |
|---|---|
| `CRON_SECRET` | пароль кронов. Без него `/api/sync/*` не запустить вручную; на проде подставляется автоматически |

## Уведомления

Нужны, только если работаешь с оповещениями по финансам.

| Переменная | Зачем |
|---|---|
| `FINANCE_TELEGRAM_BOT_TOKEN` | бот оповещений |
| `FINANCE_TELEGRAM_CHAT_ID` | куда слать |
| `FINANCE_MONITOR_SECRET` | доступ к монитору ОПиУ |

## По желанию

Без них соответствующие разделы не работают, остальная панель живёт.

| Переменная | Зачем |
|---|---|
| `ANTHROPIC_API_KEY` | разбор банковских выписок |
| `GOOGLE_SERVICE_ACCOUNT_B64` | выгрузки в Google Sheets |
| `FINANCE_SPREADSHEET_ID` | адрес таблицы для выгрузок |

---

Полный список того, что вообще читается из окружения, можно получить командой:

```bash
grep -rhoE "process\.env\.[A-Z0-9_]+" app lib components | sed 's/process\.env\.//' | sort -u
```

Большая часть оттуда относится к отдельным подсистемам и для работы над панелью
не нужна. Если какой-то раздел молчит без ошибки — сверься с этим списком: чаще
всего дело в незаданной переменной, а не в поломке.
