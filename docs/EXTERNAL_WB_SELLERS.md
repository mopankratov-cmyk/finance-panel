# Внешние WB-селлеры — запуск пилота

## Что получает селлер

- отдельную роль `seller`;
- подключение собственного WB API-токена на странице `/wb/connect`;
- только чтение аналитики собственного WB-кабинета;
- автоматическую первичную синхронизацию заказов, продаж, остатков, рекламы,
  воронки, комиссий и отзывов;
- экран контроля свежести загрузок.

Селлеру недоступны финансы компании, Ozon, сотрудники, системные настройки,
AI-агент, репрайсер и любые изменяющие WB-запросы.

## Порядок выкладки

1. Применить миграции `202607310001_external_wb_seller_tenancy.sql` и
   `202607310002_close_public_business_data.sql`.
2. Убедиться, что в production заданы `AUTH_SECRET`, `CRON_SECRET`,
   `NEXT_PUBLIC_SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY`.
3. Развернуть приложение.
4. Директор создаёт пользователя в разделе «Сотрудники» с ролью
   «Внешний селлер WB». Кабинет вручную ему не назначается.
5. Селлер входит, открывает «Подключение WB» и вставляет токен с правами
   чтения разделов: Статистика, Аналитика, Продвижение, Контент, Цены и
   скидки, Вопросы и отзывы.
6. После успешной проверки токена дождаться первичной синхронизации и
   проверить `/wb/health`.

## Приёмка перед выдачей доступа

- создать два тестовых аккаунта `seller`;
- подключить к каждому отдельный тестовый WB-кабинет;
- убедиться, что каждый видит только свой кабинет и не может выбрать `Все`;
- проверить прямой переход на `/pnl`, `/ozon`, `/users`, `/cabinets` — должен
  происходить возврат в WB-контур;
- проверить, что POST-запросы аналитических API возвращают `403`;
- деактивировать одного пользователя и убедиться, что его следующая загрузка
  данных возвращает `401`/перенаправляет на вход.

## Отзыв доступа

Директор деактивирует пользователя в «Сотрудниках» и, при необходимости,
отключает кабинет. Сессия перепроверяется по базе рядом с каждым запросом,
поэтому ждать истечения cookie не требуется.

Перенос уже подключённого seller ID в другую организацию не выполняется
автоматически: это отдельная операция владельца с проверкой права на кабинет.
