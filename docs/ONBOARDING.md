## Ежедневный цикл
1. Свежий `main`:
   ```bash
   git checkout main && git pull
   ```
2. Новая ветка под задачу:
   ```bash
   git checkout -b feat/<коротко-о-задаче>
   ```
3. Правь код (можно руками Claude Code). Проверь локально (`npm run dev`).
4. Закоммить и запушь ветку:
   ```bash
   git add -A && git commit -m "feat: что сделал"
   git push -u origin feat/<коротко-о-задаче>
   ```
5. Открой **Pull Request в `main`** (в Gitea: репо → Pull Requests → New Pull Request, base `main` ← твоя ветка).
6. Дальше работает **AI-гейт**:
   - изменение в зоне Финансы и безопасное → **вольётся автоматически** + задеплоится;
   - вне зоны / рискованное → **уйдёт владельцу** на ручную проверку (он получит уведомление).

Ты НЕ можешь пушить прямо в `main` и не можешь сам мёржить — всё идёт через гейт. Это защищает прод.

## Если что-то не так
- `git push` отбивает с «protected branch» — ты пушишь в `main` напрямую. Так нельзя: пушь в свою ветку и открывай PR.
- PR висит «нужна проверка владельца» — значит гейт решил, что изменение вне зоны Финансы или рискованное. Напиши владельцу.
- `npm run dev` падает — сначала `npm install`; не помогло → приложи вывод ошибки владельцу.
