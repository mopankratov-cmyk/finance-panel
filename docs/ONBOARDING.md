## Ежедневный цикл
1. Свежий `main`:
   ```bash
   git checkout main && git pull
   ```
2. Новая ветка под задачу:
   ```bash
   git checkout -b feat/<коротко-о-задаче>
   ```
3. Правь код и проверь локально:
   ```bash
   npm run dev
   ```
4. Закоммить и запушь ветку:
   ```bash
   git add -A && git commit -m "feat: что сделал"
   git push -u origin feat/<коротко-о-задаче>
   ```
5. Открой **Pull Request в `main`**.
6. Дальше смотри только на один из двух исходов:
   - безопасное изменение в зоне Финансы → **auto-merge** и deploy;
   - всё остальное → **ручная проверка владельцем**.

Прямой push в `main` не нужен и не работает: всё идёт через PR и гейт.

---

## Если что-то не так
- `git push` отбивает с «protected branch» — значит, пытаешься пушить не в свою ветку.
- PR висит «нужна проверка владельца» — гейт увидел риск или выход за зону Финансы.
- `npm run dev` падает — сначала `npm install`; не помогло → приложи вывод ошибки владельцу.
