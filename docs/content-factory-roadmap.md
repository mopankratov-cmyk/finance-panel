# 🏭 Контент-завод — роадмэп

Система производства UGC-контента (короткие+длинные видео) для максимума охватов и **переходов на карточки WB/Ozon**. Агент-оркестратор — **Патрик** (@mkt_aibot). Эталон UI — мокап Юры `infernoff.ru/patrick`.

## Порядок постройки (решение владельца)
1. **Система генерации** (агенты Копирайтер/Дизайнер/Видеограф + конвейер + уникализатор + AI-блогеры) ← строим сейчас
2. **Система дистрибуции** (аккаунты, антибан, мульти-постинг, расписание)
3. **Аналитика** (UTM/промокоды, переходы/заказы, канал-лидер, отбор победителей)

## Принцип (вердикт совета DMAD)
- Мерить **НЕ per-video ROAS** (на Reels/Shorts невозможно — нет прямых ссылок), а **lift внутри маркетплейса**: брендовый поиск по артикулу + скорость продаж.
- Объём почти бесплатный (своя AI-лаба) → лить много, отбирать победителей **survivorship**.
- Аккаунты — **расходник** (массовый постинг нарушает ToS → банвейвы; диверсификация, упор на брендовый спрос).

## Слой масштаба
`Мастер-контент → Уникализатор (N копий) → AI-блогеры (~20 персон) → Аккаунты (десятки/сеть → сотни, кластеры+антибан) → 8 платформ → переходы WB → измерение`

- **Уникализатор:** ре-рендер, кроп/зум, скорость ±, зеркало, аудио, метаданные, разные подписи + дедуп-трекинг (1 аккаунт ≠ 2 одинаковых).
- **AI-блогеры:** консистентный персонаж (лицо fal + голос TTS + ниша + био), ведёт кластер аккаунтов.
- **Антибан:** мобильные/резидентные прокси на кластер, прогрев, лимиты постинга/день.

## Фазы
- **Фаза 0 — Кокпит + измеримость** `[старт]`: страница «Контент-завод» (Патрик); дашборд «внешний эффект» (брендовый поиск + всплеск продаж); UTM + промокод-на-платформу; выбор товара класса A.
- **Фаза 1 — Команда + первый контент:** агенты + оживить канбан (кнопка «в работу» → лаба); валидация AI-UGC на тёплой аудитории + 1 площадка. Гейт: брендовый поиск/продажи ↑.
- **Фаза 2 — Уникализатор + мульти-постинг (1-2 площадки):** уникализатор; SMM-агент постинг/расписание; survivorship-движок отбора хуков.
- **Фаза 3 — Масштаб:** реестр AI-блогеров; аккаунт-менеджер (группы/прогрев/прокси/лимиты); bulk-постинг; бюджет-гард на кредиты.
- **Фаза 4 — Автоматизация + сеть:** комьюнити-агент, трендоскоп, 8 площадок, (опц.) инфлюенсеры-рефералы.

## От владельца (внешнее, не код)
Аккаунты (провижининг + номера/SMS) · прокси · бюджеты (Higgsfield/fal/TTS/прокси) · TTS-провайдер · принять ToS-риск.

## Гейты между фазами
Не per-video ROAS, а: брендовый поиск ↑ + продажи товара ↑ за 1-2 недели. Нет роста → проблема в товаре/хуке/доверии к AI, не в объёме.
