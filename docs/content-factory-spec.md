# Контент-завод — продуктовая спека (единый «север»)

> AI-фабрика коротких видео для селлеров WB/Ozon. Настроил рецепт под нишу один раз → завод сам делает, проверяет качество, публикует, учится на реальных результатах и предлагает улучшения. Цель — **рост аудитории (80/20)**, а не разовая реклама.

_Обновлено: 2026-06-20_

---

## 1. Целевой воркфлоу клиента (цикл)

**Подключи (1 раз)** → [ **Выбери → Делает → Одобри → Публикуй → Расти** ] ↺ повторяй каждую неделю

| Стадия | Что делает юзер | Что автоматом | Зачем |
|---|---|---|---|
| Подключи (1 раз) | подключает кабинет WB/Ozon | каталог + реальные съёмки подтянулись | вход без настроек, аха сразу |
| Выбери | 1 клик: товар или «авто: бестселлеры/новинки» | — | минимум ввода |
| Делает | ждёт ~минуты | сценарий → реальные кадры/монтаж → ОТК → текст/субтитры/звук, пачкой | качество с отбором (у конкурентов слоп без гейта) |
| Одобри | «беру / не то» (+ чипы-причины) | показываем лучшее, «не то» учит завод | калибровка без настроек |
| Публикуй | подтверждает | авто в каналы по расписанию | дистрибуция |
| **Расти** | смотрит | просмотры/аудитория, что зашло → кормит завод | **удержание + продаваемость (этого экрана сейчас НЕТ)** |

**Два момента липкости:** (1) первый заход = видео за минуты без настроек; (2) петля возврата = экран «Рост» + завод умнеет на отклонениях.

## 2. Главный принцип: настраиваемо ПОД КАПОТОМ, просто СВЕРХУ

Юзер сказал «воркфлоу должен быть настраиваемый». Но **граф/холст с нодами (генерация→анимация→нарезка→наклейки) для нетехнаря = смерть продукта** — задокументированная «ловушка конфигурируемости» (n8n/Make/Zapier проваливаются у непрофи: даже Zapier — 7% жалоб на сложность, 4.3% на кривую обучения при no-code).

Кто выигрывает у «тупого чела» — **IFTTT / Pippit / Submagic: галерея готовых рецептов + пара тумблеров**, не холст. → настраиваемость = **выбор рецепта + ручки + обучение примером**, а не перестановка блоков.

## 3. Архитектура — 3 слоя

### Слой 1 — Движок: блоки + рецепты-как-данные
Сейчас конвейер захардкожен в свитче `jobs/tick` (produce→scenario→submit→…). Выносим в данные:
- **Реестр блоков** (`lib/factory/blocks/registry.ts`): `ai_clip · real_cut · assemble · hook_text · subtitles · sticker · sound · voiceover · transition · cover · otk · overlay` — каждый = **тонкий адаптер над уже существующим роутом** (ничего не переписываем).
- **Рецепт** = JSON-шаблон шагов в таблице `factory_recipes` (по нише/бренду/режиму, с условиями «есть съёмка?» и приоритетом). `tick` → тупой **интерпретатор** шагов.
- **Новая «штука» (стикеры/движок/нарезка) = строка в реестре**, без трогания оркестратора. Каталог `FAL_VIDEO_MODELS` уже так устроен — готовая модель.

### Слой 2 — Юзер: НЕ конструктор, а 6 ручек + обучение примером
Конвейер фиксирован и виден как **читаемая лента** «сначала… потом…», не граф. Настройка живёт в 6 «ручках знания» (уже в коде): **бренд-голос · цель (Аудитория/Продажи) · источник материала · формат-пресеты · выученные промпты · отклонения.**
- «Настроить один раз» = **онбординг-мастер на 2 экрана** (~2 мин): «как звучу + цель» → «покажи что нравится» (подключи съёмку / 3-5 эталонов / «как у топов ниши») → карточка-рецепт.
- **3 жеста обучения:** показал эталон · беру/не-то (с чипами-причинами) · поправил фразой.

### Слой 3 — Мозг: самообучение + проактивные подсказки
Сейчас сигнал **выбрасывается** (фейлы <8 испаряются, оси ОТК в БД не пишутся, беру/не-то в localStorage). Чиним:
- **Единый журнал `cf_signals`**: запись на КАЖДОЕ событие (`generated` — включая фейлы <8! · `approved`/`rejected` · `published` · `metrics`) со всеми осями/движком/форматом/звуком.
- **Агрегатор по элементам рецепта** + **лестница доверия: реальные просмотры ×1.0 > беру/не-то ×0.5 > ОТК ×0.25.**
- **Веса рецепта** обновляются сглаженно → продюсер их читает.
- **Подсказки «включить одним кликом»**: редкие, объяснимые, по статзначимости («трендовый звук даёт ×2 на 12 роликах — включить? [Применить]»).

## 5. Критический мост: реальные метрики соцсети

**Самообучение без реального сигнала соцсети — фикция.** Внутренний ОТК = «нет ли брака», а не «залетело ли в ленте» (аватары проходили ОТК, но были браком в движении). Сильные подсказки решает **досмотр/охват**. → вся «обучаемость» намертво привязана к **дистрибуции** (замкнутый контур). Модель Icon.com: атрибуция «этот ХУК/формат залетел», а не «это видео залетело».

## 6. Ловушки

- Граф нельзя давать — только рецепты + тумблеры.
- Подсказки-спам → лимит **≤1/день**, гейты **n≥8, дельта ≥25%, ≥500 показов** для perf-правил. Лучше молчать, чем подсказать ерунду.
- Агрессивная авто-калибровка загонит в один формат (всё slideshow) → **сглаживание весов + ре-тест демоутнутого через А/Б**.
- ОТК по статичным кадрам ненадёжен для сильных подсказок → держать как гипотезы.

## 7. Роадмап (от дешёвого к фундаменту)

1. Расхардкодить `mode` — тумблер **Аудитория/Продажи** на товар (крошечно).

3. Реестр блоков + `factory_recipes` + интерпретатор (рефактор `tick`).
4. Онбординг-мастер + лента-конвейер + чипы-причины.
5. Агрегатор + инбокс подсказок + экран «Рост».
