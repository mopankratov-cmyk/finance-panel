# Карта интеграций Creatify → контент-завод (основа ТЗ)

> Документ самодостаточный. Все технические утверждения сверены с кодом репозитория (`lib/factory/creatify.ts`, `app/api/factory/disk-source/route.ts`, `app/api/factory/produce/route.ts`, `public/inferno/patrick.html`). Тарифные цифры, кредит-математика и поведение RU-озвучки помечены как **ГИПОТЕЗА** — требуют живой проверки на реальном ключе, их в ТЗ закладывать нельзя как факт.

---

## 0. Главное в двух абзацах

Creatify — западный SaaS для AI-UGC (api.creatify.ai). Для нашего WB-завода его ядро — **`link_to_videos` через `link_with_params`**: мы отдаём фото карточки WB напрямую (`image_urls`), товар не перерисовывается, актёр-аватар комментирует, b-roll добирается стоком или нашими видео. Это уже встроено (кнопка «🎭 UGC-актёр», роуты `/api/factory/ugc-creatify(+status)`, пикер 1500+ аватаров). **Но в production это ещё ни разу не прогонялось живьём** — ключей `CREATIFY_API_ID/KEY` нет в Vercel, значит `creatifyReady() === false` и все роуты инертны.

Любой AI-UGC от Creatify обязан проходить ОТК-гейт (video-critic / hook-judge), любой англоязычный CTA/субтитр = брак, товар WB всегда идёт фото без перегенерации. **Перед любой содержательной работой нужно снять три блокера (волна 0): купить именно API-план, проставить ключи, провести одну живую проверку русского ролика.** Пока это не сделано, всё ниже — гипотезы.

## 1. Что Creatify умеет и что из этого API-доступно

### 1.1. Ядро для нас (используем)
| Возможность | Суть | API |
|---|---|---|
| **URL-to-Video / `link_to_videos`** | Из Link → короткий UGC-ролик с показом товара (актёр + b-roll). Двухшаговый рендер: `generate_preview` → `render`. | да |
| **`links/link_with_params`** | Создать Link вручную из `title/description/image_urls[]/video_urls[]` — обход того, что WB не скрейпится. Это наш проверенный путь. | да |
| **Personas (1500+ аватаров)** | Листинг и фильтрация сток-аватаров + override_avatar. Уже обёрнуто (`creatifyListAvatars`). | да (GET бесплатно) |
| **Visual style / сцены** | Каталог композиций (AvatarBubble / SideBySide / TopBottom…). Уже в коде (`CREATIFY_SCENES`). | да |
| **Lipsync v1/v2** | Актёр говорит наш текст без товара в кадре. У нас — только запас (на вход FAL-гибриду). | да |
| **TTS + каталог голосов** | `/text-to-speech/`, `GET /voices/`. Русский заявлен в списке языков. | да |
| **Custom Avatar BYOA** | Свой диктор из consent-видео (`/personas_v2/`). Ревью ~24ч. Мост к «реальному UGC без синтетики». | да (квота зависит от плана) |
| **Workspace credits** | `GET /workspace/remaining-credits/` — гейт перед батчем. | да (бесплатно) |
| **Webhooks** | `webhook_url` — callback вместо поллинга. В доках подтверждён **только для custom_template_jobs**; для link_to_videos — догадка. | гипотеза |
| **Batch (до 50)** | Пачка вариаций под хук-турнир. Лимит на API Starter не подтверждён. | да (лимит проверить) |
| **Ad Clone** | Клон вирусного референса со своим товаром. Высокий риск искажения товара. | да |

### 1.2. Что Creatify умеет, но нам НЕ подходит (детали в разделе 4)
Product-to-Video (`gen_image` перерисовывает товар), AI Shorts (DEPRECATED), IAB Images / AI Face / Meme / AI Product Photography (синтетика/перерисовка, не видео-UGC), Ad Intelligence / Inspiration / Competitor tracker (западные данные, дублируют Virlo).

### 1.3. Тариф и доступ к API — **ГИПОТЕЗА, не факт**
По публичной потребительской таблице тарифов API стоит только у Enterprise — отсюда исходное предупреждение «возможно только Enterprise». Есть рабочая гипотеза, что у Creatify существует отдельная линейка API-планов (API Starter ~$99/500кр, API Pro ~$299/2000кр), и тогда минимальный реалистичный тариф = API Starter. **Это НЕ проверено живым запросом в этой сессии** и противоречит исходному предупреждению задачи. Критично: «API Starter $99» и «Studio Pro $99» — разные продукты по одной цене; купленный Studio-план ключей не даёт.
→ **Действие для владельца: подтвердить на странице биллинга, какой именно план куплен и даёт ли он `X-API-ID/KEY`. Вся дорожная карта висит на этом.**

### 1.4. Кредит-математика — **ГИПОТЕЗА, занижена в реальности**
Расчёт «60+ роликов/мес на 500 кр» опирается на (1) `aurora_v1_fast` = 0.5 кр/сек и (2) ролик ровно 15с. В коде `video_length` действительно захардкожен 15 (`creatify.ts:144`), но виральные UGC обычно 20–30с → 12–15 кр/ролик. Плюс каждый провал ОТК и перегенерация жгут кредиты заново. **Реалистичная пропускная способность с учётом брака и regen — порядка 15–25 готовых роликов/мес, а не 60+.** В ТЗ закладывать консервативную оценку.

## 3. Дорожная карта волнами

### Волна 0 — РАЗБЛОКИРОВКА (без неё всё инертно)
1. **Подтвердить и купить именно API-план** (не Studio Pro $99) — иначе ключи не выдадут. Тариф пометить как гипотезу до проверки биллинга.
2. Проставить `CREATIFY_API_ID` + `CREATIFY_API_KEY` в Vercel env.
3. **Проверить доступность из РФ/Vercel-региона**: биллинг (карта), сам API, CDN-выдача готовых mp4 (см. риски, раздел 5).
4. Live-валидация: дёрнуть `/creatify-avatars` (диагностика встроена в `creatifyListAvatars`) → сразу видно, работает ли API на тарифе.
5. Прогнать 1 реальный `link_to_videos` по живому товару WB → проверить русскую озвучку/субтитры, отсутствие англо-CTA, корректность preview→render.

### Волна 1 — СЕЙЧАС (после разблокировки)
- **Пререквизит-блокер:** публичные URL для дисковых видео (прокси) — уже сделано, `disk-source` отдаёт `url` для видео.
- `video_urls[]` + `no_stock_broll` — следующий фокус: реальная съёмка в Creatify-ролик (мост пивота).
- `override_voice` — русский голос бренда (`override_script` уже есть, не дублировать).
- `no_music` по умолчанию + опция `no_caption` с нашим русским overlay.
- Гейт остатка кредитов в кокпите.
- **Фикс preview→render** (убрать авто-рендер первого превью; render теперь запускается отдельным route).
- **Frames-извлечение** для ОТК Creatify-роликов (иначе гейт слепнет).
- Фикс `aspect_ratio` `9x16` vs `9:16`.

### Волна 2 — СЛЕДУЮЩЕЕ
- Серверный persist job→result (анти-потеря оплаченных рендеров).
- `real_ugc`: снять демоут аватаров + автозвать `ugc-creatify` (route уже существует — это НЕ «добавить route»).
- Batch Generation под хук-турнир (после гейта кредитов + атомарный учёт).
- BYOA (реальный диктор) — мост к UGC без синтетики.
- `override_avatar_by_image` как развилка к BYOA.
- Webhooks (если link_to_videos реально шлёт callback — проверить live).

### Волна 3 — ПОЗЖЕ (под доказанную ценность и ОТК)
- Ad Clone вирусного референса со своим товаром.
- `model_version` тумблер standard↔aurora.
- Custom Templates под brandProfiles.
- Standalone TTS для гибрид-склейки.

## 4. Что НЕ берём и почему

| НЕ берём | Причина |
|---|---|
| **`product_to_videos` (`gen_image`/`regen_image`)** | Перерисовывает превью товара по `image_prompt` → для карточки WB гарантированный брак ОТК. Товар показываем через `link_to_videos` (image_urls без перегенерации) или slideshow. |
| **AI Shorts** | Помечен DEPRECATED, Creatify сам уводит на URL-to-Video/AI Avatar. Наш аналог — slideshow/video-fal. |
| **IAB Images / AI Face / Meme / AI Product Photography** | Статичные баннеры/синтетические лица/перерисовка — вне фокуса (видео-UGC) и риск брака. Реальный товар всегда фото. |
| **Ad Intelligence / Inspiration / Competitor tracker** | Аналитика по западным площадкам, не по WB/RU-TikTok. RU-инсайты берём из Virlo Orbit (уже встроено). |
| **Гибрид на движке Creatify вместо FAL** | НЕ конкуренты, а связка: FAL-`hybrid-compose` берёт `actor_video_url` именно из готового Creatify-lipsync (`patrick.html:1689` — «сначала создай UGC-актёра»). Менять движок склейки смысла нет — FAL дешевле/гибче. |

## 5. Открытые вопросы для владельца и live-проверки

**Блокеры (волна 0):**
1. **Тариф:** куплен ли именно API-план (даёт `X-API-ID/KEY`), а не потребительский Studio Pro $99? Подтвердить на странице биллинга — вся карта висит на этом. *(гипотеза, не проверено живьём)*
2. **Ключи:** проставлены ли `CREATIFY_API_ID` + `CREATIFY_API_KEY` в Vercel? Без них `creatifyReady()=false`, все роуты возвращают 503.
3. **Геоблок/доступность из РФ:** работают ли из российской инфры / Vercel-региона: оплата картой, сам API, выдача готовых mp4 с CDN? В памяти проекта есть network-constraints по WB — тот же класс риска не снят для Creatify. Может убить интеграцию до тарифа.

**RU-качество (под ОТК):**
4. На живом ключе реально ли `link_to_videos` отдаёт русскую озвучку + русские субтитры и НЕ вставляет англо-CTA при `language='ru'`+`no_cta`? `no_cta` убирает только финальную плашку — англо-субтитры/текст на сток-b-roll он НЕ покрывает. *(опыт HeyGen: аватары убирали за качество — риск робото-русского/зловещей долины высокий)*
5. Какие `voice_id` в `GET /voices/` дают НЕ робото-слоп по-русски? Нужен короткий аудит каталога + маппинг бренд→голос.
6. `override_script` (наш русский текст) vs авто-сценарий из `link_data`: не уходят ли русские title/description карточки в озвучку и не конфликтуют ли с нашим скриптом?
7. Сохраняет ли `link_to_videos` товар «как на карточке»? Даже без `gen_image` AI-композитинг, авто-кропы, цветокор и сток-врезки могут исказить восприятие (цвет/фактура/чужой контекст). «Не перерисовывается» верно для пикселей фото, но не гарантирует «товар как на WB» в глазах критика.

**Технические (требуют live):**
8. **`video_urls`:** реально ли Creatify ВСТАВЛЯЕТ наши видео, или игнорирует/перекрывает стоком даже при `no_stock_broll`? Публичные URL для дисковых видео уже есть — теперь нужен live-check на самом Creatify.
9. **Идемпотентность `/render/`:** `creatifyStatus` дёргает render при каждом опросе (`:193`) — не запустит ли это несколько платных рендеров одного видео? Перерасход кредитов.
10. **Парсинг ответа:** код берёт `video_output||output` и `status` строкой (`:185-187`). Имена полей не зафиксированы доками (как уже видно по personas: `results||data||массив`) — риск, что готовое видео не распознается и завод считает его «in_progress» вечно.
11. **Webhooks:** шлёт ли `link_to_videos` callback, или это только `custom_template_jobs`? Если только шаблоны — оставить поллинг.
12. **Кредиты:** точное имя поля в `GET /workspace/remaining-credits/` + реальная стоимость 15с и 30с ролика на `aurora_v1_fast` (теория 7.5 / 15 кр).
13. **Batch-лимит:** сколько вариаций реально разрешено за раз и не выжжет ли пачка месячный баланс? Нужен атомарный учёт (гонка между чтением баланса и запуском).
