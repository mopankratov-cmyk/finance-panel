# Drill Loop: петля обучения «идеальный блогер» (план 2026-07-02)

Задание владельца: «одни и те же лица в разных ракурсах, стилях, подачах; ~100 роликов;
петля обучения; уроки запоминать и писать в код».

## Почему эта петля сработает (в отличие от Катиного лупа)

Катин луп упёрся в fixed point, потому что скорер оценивал ПЛАН, а не результат.
У Drill Loop три органа, которых у него не было:
1. **Глаза** — vision-критик: кадровые полосы каждого клипа судит агент по рубрике
   (identity / свет / живость / кожа / артефакты / UGC-feel).
2. **Вкус** — вердикты владельца в Telegram = ground truth. Критик ПЕРЕКАЛИБРУЕТСЯ
   под вкус владельца после каждого батча (совпадение вердиктов = метрика критика).
3. **Память** — уроки промоутятся в КОД (канон-модули: antiAiPost, productComposite,
   bloggerRegistry variant records), а не в чью-то голову. Валидируются контракт-тестами.

## Решение: сверлим ОДНУ — Маню

100 роликов на одну девушку, а не 33×3: одна identity-переменная, быстрее сходимость.
Перенос на Вику/Олю уже доказан (канон-рецепт воспроизвёлся с первого прогона).

## Оси исследования (что варьируем)

| Ось | Значения | Источник |
|---|---|---|
| scene/look | 15 луков + деглянц-варианты (вечер/день/улица/машина/зеркало) | паспорт |
| свет | лампа-вечер / солнце-пятна / пасмурно / улица | деглянц-промпт |
| framing | крупняк / полукорпус / зеркало-рост | look |
| motion | 13 пресетов + микро-реакции (до/после фразы) | bloggerMotion |
| подача | голосовуха / рассказ подруге / скептик / уставшая / заговор | скрипт+emotion |
| скрипт-стиль | филлеры («ну, короче»), паузы, КАПС-ударения, длина | редактор пауз |
| expressiveness | low / medium | Avatar IV |
| пост | зерно / резкость / тряска / грейд в узких диапазонах | antiAiPost |

Аниматор зафиксирован (HeyGen Avatar IV, чемпион 33:30), 1080p. Раз в ~3 батча —
контрольный клип OmniHuman/Mirage для ре-валидации выбора.

## Механика батча (10 клипов)

1. **План**: батч исследует ОДНУ ось глубоко (не случайная сетка) + 2 контрольных
   клипа с лучшими параметрами прошлого батча (регрессия-чек). Анти-повтор комбо.
2. **Рендер**: канон-конвейер (деглянц при новой сцене → TTS → Avatar IV 1080p → адаптивный пост).
3. **Критик**: полосы → агент-судья → скоры по осям в леджер.
4. **TG**: владельцу — только топ-3 батча. Вердикты («верю»/«палится»/что цепляет) — в леджер.
5. **Анализ**: корреляция параметры↔скоры↔вердикты → выводы:
   - параметр стабильно выигрывает → **промоут в канон** (код + тест);
   - стабильно проигрывает → в чёрный список оси;
   - критик разошёлся с владельцем → правка рубрики критика.
6. Журнал: docs/factory-blogger-drill-ledger.json (в РЕПО, не /tmp) + ночной лог.

## Объём и деньги

- 10 батчей × 10 клипов = 100 роликов Мани.
- Цена клипа ≈ $0.5–0.7 (Avatar IV 1080p ~8с) + деглянцы ~$0.05 + TTS копейки + пост $0.
- **Итого ≈ $60–75**, батч ≈ $6–7. Пополнения HeyGen-кошелька по ходу (скажу заранее).
- Темп: 2–3 батча в день (рендер ~40 мин/батч + твои вердикты асинхронно).

## Критерий завершения

Двойной гейт три батча подряд: (а) владелец даёт «верю» ≥2 из топ-3;
(б) критик-скоры стабильны (не растут) — значит, выучили всё, что можно на этой архитектуре.
Выход: «Библия Мани» — канон-параметры в коде + карта выигрышных комбо в реестре +
откалиброванный критик, который дальше судит ВМЕСТО владельца (его вкус выучен).
