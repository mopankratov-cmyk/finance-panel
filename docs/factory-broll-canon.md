# Канон b-роллов (агент-«монтажёр»)

Зафиксированный ОДИН РАЗ стиль моушен-графики, который агент применяет ко всем b-роллам без поштучного
промптинга. Источник правды для `remotion/BRoll.tsx` + `lib/factory/brollSpec.ts` + `app/api/factory/broll`.

## Идея

Агент-«монтажёр» получает СЦЕНАРИЙ + одну строку-бриф («сделай 3 динамичных b-ролла по 4с»). Сам:
1. читает сценарий, находит **N самых сильных фраз** под визуализацию (хук / боль / ирония / кульминация / цифра-доказательство);
2. назначает каждой **форму** (preset) + акцент + (для цифр) stat;
3. детерминированно собирает спеку (`buildBRollSpec`) и рендерит **чистую моушен-графику** через Remotion-VM (композиция `BRoll`).

🔑 **B-роллы рендерятся ИЗ КОДА (CSS/SVG), без медиа и без fal** → дёшево, быстро и **не зависят от баланса fal**.

## Дизайн-система (фикс)

- **Фон:** тёмный графит (`#0e0f12 → #15171a`), живой: дрейфующее радиальное свечение акцента + медленно ползущая сетка + лёгкий зум. **Каждый кадр в движении.**
- **Акцент:** 1 основной на ролл, **не более 2-3 разных акцентов на весь ролик**. Палитра: `orange #ff5a1f · cyan #22d3ee · lime #a3e635 · violet #a78bfa`.
- **Типографика:** заголовки — Unbounded/Montserrat (жирный, кириллица); **цифры — моноширинным** (`JetBrains Mono`/system mono, `tabular-nums`).
- **Анимация:** плавная, **БЕЗ отскоков** — overdamped spring (`damping 22, stiffness 100, mass 0.6`; нет overshoot). Строки приезжают снизу с клипом, акцентная — цветом + анимированное подчёркивание. Снизу — акцент-прогресс-бар (движение в каждом кадре).
- **Формат:** 1080×1920 @30fps, 4с по умолчанию (кламп 2–8с).

## Пресеты

| preset | когда выбирает агент | как выглядит |
|---|---|---|
| **cascade** | обычная фраза (дефолт) | фраза каскадом по строкам, последняя — акцентом + подчёркивание |
| **quote** | короткая ударная мысль (≤3 слова) | одна крупная фраза по центру + акцент-бар сверху |
| **stat** | во фразе есть число | крупное моноширинное число «набегает» (counter) + подпись + опорная строка |

## Контракт (props композиции BRoll)

```ts
{ durationInFrames, preset, accent, accent2?, kicker?, lines[], emphasizeIndex?, stat?{value,label} }
```

Агент эмитит подсказки (`phrase/preset/accent/kicker/stat`) → `buildBRollSpec` нормализует в валидные props
(кламп строк ≤4, длительности 2–8с, акцент: имя→hex или ротация по индексу). Композиция props-driven —
агент НЕ пишет произвольный React, поэтому рендер не ломается (надёжнее, чем agent-writes-code à la Hyperframes).

## Поток / API

`POST /api/factory/broll { script, count?=3, brand?, accent?, durationSec?=4 }`
→ Claude выбирает фразы (temperature 0.5) → `buildBRollSpec` ×N → `remotionSubmit("BRoll", spec)` (VM) → опрос →
`{ ok, rendered, brolls:[{phrase, preset, spec, url|id|error}] }`. Без `REMOTION_RENDER_URL` вернёт спеки без рендера.

## Самопроверка (ОТК)

Кадры b-ролла можно прогонять через существующий видео-критик (`/api/factory/video-critic`, basis=кадры) для
авто-QA читаемости/контраста/«AI-слопа», затем чинить спеку и пере-рендерить (петля без оплаты fal).

## Чего НЕ делать

- ❌ Поштучный промптинг каждого ролла. Стиль — ЗДЕСЬ, агент только выбирает фразы/форму.
- ❌ Отскоки/bounce-springs, более 3 акцентов, пропорциональные (не tabular) цифры, статичные кадры.
- ❌ Агент пишет произвольный React-код композиции (хрупко в автоматике). Только props-spec.
