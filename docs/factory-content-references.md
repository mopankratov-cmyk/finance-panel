## Стратегические находки (кто выигрывает и где дыры)

1. **RU-бренды Pinterest почти не занимают.** Серьёзно работает только 12 STOREEZ (11.7k, Verified Merchant, чистый editorial без текста). LOVE REPUBLIC (1.3k) — единственный с трендовыми подборками-коллажами. Остальные спят.
2. **Выигрывают не бренды, а WB-кураторы:** «Находки на WILDBERRIES» (13.4k) и CapsulesWB (8.6k) — форматы «товар/коллаж + артикул поверх картинки + воронка в TG». **Это готовый нативный формат для наших твинов** — ни один бренд его не использует.
3. Pinterest сам генерит идея-хабы «Пальто 2026 тренды ВБ», «Пуховик 12 Storeez» — **WB-интент на Pinterest реальный и большой**, обслуживают его кураторы-любители с слабыми картинками. Чистые AI-твины их переигрывают по качеству на порядок.
4. **Карточки WB (мета из 45 топ-карточек):** раскол по цене — масс (1.2–6к₽) кладёт инфографику на слайды 1–3, премиум (9–18к₽) идёт чистым editorial, УТП в названии. **Температурный бейдж — универсальный числовой хук ниши** («до −30°C», «+10/−10») — есть почти на каждом текстовом слайде. Обязательный набор слайда 1: категория+сезон крупно, температура с иконкой, размерная плашка в углу («42-60»).

## Видео-грамматика (для Wibes/reels)

- **Хук ≤3с:** товар-в-лицо крупно ИЛИ текст-заявка («идеальный пуховик») ИЛИ неожиданная деталь («скрытый карман!»)
- Форматы: распаковка / демонстрация фич (по фиче на бит: швы, молнии, подкладка) / в-действии / на модели / **анимация пэкшота (наш твин-лейн)** / styling-5-ways (доминирует на Pinterest: 1 вещь × 4–5 образов по 2–4с с лейблом) / layering-demo (куртка = финал) / roundup 20 моделей по 1.5–2с
- Артикул-слой всегда: «Арт:» подписи у элементов, артикул-эндкард

## Анти-паттерны (не делать)

- Expectation-vs-reality мемы — 90% фейл-контент Shein/Ali, анти-продающий. Но страх реальный: закрывать его слайдом «фото = реальность» (твин + реальное фото покупателя) и макро-фактурой ткани
- Крео-хаос: >1 сообщения на кадр; текст по углам вместо центра; квадратные пины (−40–60% показов)
- Kling-развороты одежды (см. пилот: брак) — только вайтлист движений + кадровый ОТК

## Как «обучаемся» на этом

1. **Стиль-референсы для nano-banana:** публичные URL из bucket подаются вторым изображением в edit-промпты («сделай в стиле референса, товар не менять»)
2. **Промпт-константы:** мастер-паттерны 1–8 → шаблоны в staticCanon/reelFormats (плашечная система WB, капсульный грид, цвето-чипы)
3. **gbrain:** паттерны и стратегия зашиты страницами в мозг флота (см. страницы reference-*)
4. **Следующая итерация** («перебедим фиксов»): собрать по одному образцу на паттерн из наших твинов → отсмотр владельцем → закрепить победителей кодом

## MAXFAME — эталонный конкурент (найден владельцем, 05.07)

**ru.pinterest.com/maxfame_ru** — «ветровки / куртки / пуховики. Верхняя одежда с ВБ» = категория NORVIA 1-в-1.

- **22 подписчика / 866 300 просмотров в месяц** — рекорд класса, почти уровень топ-куратора
- **Био слово-в-слово = MONAPURE** → одна команда/агентство гоняет ферму бренд-аккаунтов (сеть, не одиночки)
- Ссылка через шортенер **wburl.ru** (трекинг)
- **Объём: ~1 540 пинов/месяц** (доски: Как одеваться весной 284/3нед, Образы весна-лето 270/3нед, Образы на лето 297/4нед, Куртки на весну 145, Капсула 206, Луки с ветровкой 183, Образы с ветровками 158) = **30–50 пинов/день**
- **Движок = пин-на-цвет:** серия созданных пинов «Ветровка WB 861404027…861404032» — одна модель, 6 последовательных артикулов-цветов, каждому цвету свой пин с шаблонной плашкой «Ветровка WB <арт>» на стрит-фото. Есть и видео-пины
- Экономика: ~575 просмотров/пин/мес в среднем; даже при CTR 1–2% это >10к бесплатных переходов на WB в месяц

**Вывод для NORVIA:** стратегия «цветовая линейка → пин на каждый колорвей с артикулом» уже промышленно провалидирована в нашей категории. Наше преимущество: твины с идентичной геометрией дают этот конвейер бесплатно и чище (у MAXFAME — разношёрстные стрит-фото), плюс мы можем видео и WB-инфографику, которых у сети нет. Целевой темп для конкуренции: не 3–5, а 15–30 пинов/день (по пину на SKU × ротация досок-рубрик).
