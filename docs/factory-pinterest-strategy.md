## Часть 1 · Анализ: как устроена машина конкурентов

### 1.1 Карта игроков

| Игрок | Тип | Подписчики | Просмотры/мес | Воронка |
|---|---|---:|---:|---|
| **MAXFAME** (ветровки/куртки/пуховики) | бренд-аккаунт сети | 22 | **866 300** | wburl.ru/pinterest26 → WB |
| **MONAPURE** (куртки/ветровки/бомберы) | бренд-аккаунт той же сети | 177 | 206 400 | деплинк wildberries.ru/brands/… |
| VERH (жен. одежда) | бренд-селлер | 21 | 139 900 | пин → пост t.me + WB |
| «Находки на WILDBERRIES» | куратор | 13 500 | 920 200 | t.me |
| CapsulesWB | куратор (Y2K, 18–25) | 8 600 | 110 000 | t.me |
| 12 STOREEZ | бренд-издатель | 11 700 | — | editorial, Verified Merchant |

**Факт 1:** MAXFAME и MONAPURE — слово-в-слово одинаковые био → **одна команда, ферма аккаунтов**. Конкурент — контент-агентство, не бренд.
**Факт 2:** подписчики не значат ничего (22 → 866k). Pinterest раздаёт через SEO/фид. Но важно: **все компараблы — зрелые, прогретые фермой аккаунты**; для холодного старта их цифры — потолок, не бейслайн.

### 1.2 Операционка MAXFAME (по секундам, из RSS)

- **15–20 собственных пинов/день**, 1–2 вечерних залпа по 8–10 пинов с интервалом 20–30 сек → **шедулер/балк-инструмент**.
- **+ ~30 репинов/день** в SEO-доски → суммарно ~50 единиц/день, ~1 540/мес. **Репины = ~60% объёма** — это их механизм засева досок и объёма, не побочка.
- Доски = SEO-рубрики, брендированные обложки; карусель-пины (стрип миниатюр) у MONAPURE.
- ~575 просмотров/пин/мес — но это **сток-метрика зрелого каталога** (весь бэк-каталог зарабатывает на трейлинг-30d), не «сколько заработает наш свежий пин».

### 1.3 Анатомия их пина

1. Живая модель, стрит-стайл, естественный свет — «из ленты блогера», не каталог.
2. Минимальная чёрная/белая плашка в углу: «Ветровка WB» + артикул.
3. **Пин-на-цвет:** серия артикулов 861404012→032 — каждый колорвей = свой пин.
4. Тайтл-«колбаса» ~30 ключей + ~20 хэштегов (таксономия в docs/factory-content-references.md).

### 1.4 Механика платформы (почему работает)

- WB-интент институционализирован: чипы «Артикул», «Вб», «На кулиске» (= имя нашей NV-08!) в выдаче.
- Топ WB-запросов — пины с артикулами на картинке. AI-контент не подавляется (проверено).
- Реклама/каталоги для РФ отключены → игра = объём × SEO × свежесть, органика-only.

### 1.5 Слабости сети (наши окна)

1. Ноль видео. 2. Нет палитра-гридов/свитчей (топ-формат по сохранениям 2×). 3. Нет инфографики ниши (температурный бейдж). 4. Безликий бренд-слой. 5. Фото-зависимость: каждый дроп = съёмка; у нас ~$0.04/пин. 6. ЦА 30–45 обслужена слабее всех (CapsulesWB — Y2K).

## Часть 2 · Стратегия NORVIA

### 2.1 Аккаунт: заведение и прогрев (критично — по чеклисту)

- **Business-аккаунт** (обязательно: без него нет аналитики и нативного шедулера). Отдельный browser-профиль, свой email; claim трекер-домена — как появится.
- Хэндл norvia_ru; имя профиля «NORVIA: куртки | ветровки | пуховики. Верхняя одежда с ВБ»; био = УТП брендбука; ссылка = бренд-страница WB + UTM; баннер = групповой шот цветовой линейки из твинов.
- **Прогрев против спам-метки:** дни 1–3 — только доски + репины + 2–3 пина/день; выход на 10/день к дню 6–7. (10/день с аккаунта возраста 0 — спам-паттерн; у сети аккаунты выдержанные.)
- **Резерв:** параллельно завести второй аккаунт и тихо греть репинами — горячий запасной на случай бана (у сети ферма, у нас иначе single point of failure).
- Месяц 2: заявка на **Verified Merchant** (у 12 STOREEZ есть — доверие+атрибуция).

### 2.2 Публикация: решение принять в день 0

Три механики, выбор по тесту на 3 черновых пинах ДО старта:
1. **Нативный шедулер** business-аккаунта (грузит по одному, лимит очереди, поведение с видео из РФ — проверить).
2. **Ручные залпы** из browser-профиля: оценка 15–20 мин/залп из готового манифеста → 30–45 ч/мес на полном темпе — реальная стоимость, учтена в бюджете.
3. **Антидетект-воркер** (архитектура уже спроектирована: docs/factory-publishing-architecture.md, ProxyShard→ShardBrowser) — целевое состояние; «3× темп сети» возможен ТОЛЬКО после его запуска.

Завод в любом случае выдаёт манифест (файл+тайтл+описание+alt+доска+UTM+теги) — docs/factory-pinterest-wave*.json.

### 2.3 Форматы (матрица с квотами)

**Ядро (их формат, лучше исполнение):**
| Формат | Козырь | Квота |
|---|---|---|
| Пин-на-цвет · стрит (v3-P2 + плашка) | RU-классицизм сцены, идеальная геометрия | 5–7/день |
| Пин-на-цвет · студия (v3-P3, SHIP) | WB-карточный уровень | 3–5/день |
| Тональный интерьер (v3-P1 fix) | премиум-слой | 2/день |
| **Репины** (чужой контент в тематические доски + кросс-репины своих) | засев SEO-досок, ~нулевая кость | **10–15/день** |

**Асимметрии (у сети нет):**
| Формат | Квота |
|---|---|
| Палитра-грид 9 цветов | 1/день |
| Видео-пин свитч цветов (9:16, ≤15с, MP4, обложка с плашкой) | 1/день |
| **Карусель** (2–5 кадров: колорвеи + эндкард с артикулами — механика MONAPURE) | 1/день |
| Коллаж «подбор образа» (жёсткая сетка) | 2/день |
| Инфографика-пин (температурный бейдж, размерная плашка) | 1–2/день |
| Листикл «N способов» + вопрос-биллборд («Как стилизовать…?») | 2–3/нед |

### 2.4 SEO-система (в лимиты платформы)

- **Тайтл ≤100 знаков:** главный ключ в первых 40 + 2–3 хвоста. «Колбаса» НЕ в тайтл.
- **Описание ≤500 (оптимум 220–232):** сюда длиннохвост ~15–20 фраз + цена + CTA + артикул.
- **Alt-text** каждому пину. **Хэштеги:** таксономия сети (20) + #накулиске #norvia.
- Имена цветов = SEO («капучино», «тёмно-зелёный») в тайтлах. Ключи по моделям = чипы выдачи («куртка с кулиской» и т.д.).

### 2.5 Доски (8) + протокол засева

Список: «Куртки женские демисезон 2026» (NV-08) · «Куртки с поясом — образы» (NV-816/01) · «Парки женские осень-зима» (NV-836) · «Ветровки женские» (HT — **заблокировано до правок Андрея**) · «Капсульный гардероб на осень» · «С чем носить куртку» · «Цвета сезона 2026/27» · «NORVIA новинки».
**Каждая доска ПЕРЕД первым своим пином получает 10–15 качественных репинов по своему ключу** — иначе related-граф не цепляется.

### 2.6 Операционный runbook

- **Оператор недель 1–4:** владелец (или Артём), 2 окна: ~12:00 и ~18:30 МСК (окна сети; распределение по дням недели снять из нашего RSS-мониторинга и скопировать, не гадать). 15–20 мин/залп по манифесту + 5 мин на комментарии.
- **SLA комментариев: 1 проход/день** — в этой нише комменты = «скиньте артикул» = прямая конверсия. Шаблон ответа: артикул + деплинк с UTM.
- Граница ответственности: завод генерит и раскладывает манифесты; человек жмёт публикацию (до воркера).
- Выходные: те же 2 окна, сокращённая квота (по RSS-данным сети скорректируем после первого снимка).

### 2.7 Экономика (честная)

- **CTR-база: 0.2–0.6% (кейс 0.3%)**, не 1–2%: на 90-дневной цели это ~900–1 500 отслеженных переходов/мес. Плюс неотслеживаемый канал: люди ищут артикул руками на WB → мониторим позиции своих артикулов в поиске WB как вторичную метрику.
- **Модель просмотров — двухпараметрическая:** свежий пин холодного аккаунта: 50–200 просмотров в первые 30 дней; ретеншн хвоста 40–60%/мес. «575/пин» сети — сток зрелого каталога, не наш бейслайн.
- **Бюджет:** FAL $55–75/мес на полном темпе (включая ~30% на регенерацию после реджектов); floor баланс-гарда поднять с $2 до **$10**. Труд публикации: 30–45 ч/мес до воркера — главная скрытая кость.
- **QC двухуровневый:** автоматический identity/geometry-гейт на **100%** финальных пинов (расширение твин-гейта — «фото=реальность» обязывает) + 3-линзовый судья на 10% выборке. HT-ветровки жёстко вне ротации до правок.

### 2.8 Цели с калибровкой (вместо хотелок)

- **Калибровочный гейт, день 14** (после 10/день): медиана просмотров/пин. **≥100/мес** → включаем ramp месяца 2; **30–100** → держим темп, крутим SEO; **<30** → стоп, диагностика песочницы/спам-метки.
- **Чекпойнты:** день 14 ≥5k просмотров профиля/мес; день 30: **база 15–50k** (50k+ = стретч); день 90: **150–350k**; месяц 6: **база 350–500k, стретч 800k** — с EV-дисконтом на RU-замедление (тренд −20–27%) и риск блокировки: **матожидание месяца 6 ≈ 200–350k**.
- Не сошлось с чекпойнтом → ревизия SEO/форматов по петле, не «пиним дальше».

### 2.9 Отказы и пороги

- Бан/спам-метка основного аккаунта → переключение на прогретый резерв за 1 день (манифесты вне платформы, конвейер не привязан к аккаунту).
- Незакрытая зависимость (пресет-фикс, HT-правки) → замещение объёмом P2/P3, суточная квота не падает.
- Ужесточение RU-замедления → тот же конвейер зеркалится в TG-канал и VK (форматы совместимы), Pinterest остаётся SEO-хвостом.

### 2.10 Метрики: инструменты и владелец

- **Еженедельный снимок (владелец процесса — завод, автоматом):** RSS всех 7 конкурентов (темп/форматы), просмотры профиля/мес, топ-пины по сохранениям/кликам.
- **Позиции по 6 ключам:** ручной протокол — чистая сессия (гостевая вкладка), скриншот топ-20, фиксация позиций своих пинов; раз в неделю. Ключи: «куртка женская вб», «пуховик женский», «с чем носить пуховик», «на кулиске», «куртка с поясом», «капсульный гардероб осень».
- **UTM-схема:** utm_source=pinterest, utm_medium=organic, utm_campaign=<артикул>-<формат> (per-SKU-формат) → кабинет WB «внешний трафик» (+комиссия-кат).

## Часть 3 · Контент-план: первые 30 дней

**День 0 (подготовка):** business-аккаунт + browser-профиль; тест публикации (3 черновых пина через шедулер И руками — фиксируем выбор); финал-фиксы пресетов (P1-крем, P2-поза, коллаж-мелочи).

**Дни 1–3 (прогрев):** 8 досок + по 10–15 репинов в каждую; 2–3 своих пина/день (лучшие SHIP-кадры); био/баннер.

**Дни 4–7 (выход на 10/день):**
- NV-08: стрит ×9 цветов + палитра + свитч-видео
- NV-816: стрит ×8 + палитра + карусель
- NV-836: стрит ×8 + палитра + инфографика (температура)
- NV-01: стрит ×8 + палитра + свитч-видео
- + репины 10–15/день фоном

**Неделя 2 (10–12/день):** вторые пресеты тем же SKU (студия↔стрит), коллажи ×2/день, листикл + вопрос-биллборд, A/B плашки (чёрная/белая).

**Дни 14: калибровочный гейт** (см. 2.8) → решение о ramp.

**Недели 3–4 (при зелёном гейте, 15–20/день двумя залпами):** третьи пресеты; интерьер-P1; сезонный клин — **первые пины «пуховик зима 2026/27» уже в июле** (фора 45–90 дней); HT-ветровки если правки пришли, иначе замещение; недельный RSS-снимок → подстройка.

**Выход месяца:** ~300–350 своих пинов + ~350 репинов, 8 живых досок, петля метрик и калибровка пройдены.

## Часть 4 · Сводка «чем лучше»

1. **Видео + карусели + палитры + инфографика** — четыре формата, которых у сети нет, все уже в конвейере.
2. **Экономика контента:** равный собственный темп (15–20/день) при ~1/100 их себестоимости кадра; 3× — после публикационного воркера.
3. **Бренд-слой:** wordmark, палитра, tone, «фото=реальность» с настоящим identity-гейтом на 100% пинов.
4. **Петля:** судьи + рефы + RSS-шпионаж еженедельно — мы итерируем быстрее, чем они снимают фотосессию.
5. **ЦА-фит:** 30–45 обслужена слабее всех — наш брендбук бьёт ровно туда.
