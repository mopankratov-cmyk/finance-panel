# Канон промптинга Контент-Завода

Источник правды для всех трёх стадий генерации. На него ссылаются код (`lib/factory/editPrompts.ts`),
системные промпты ИИ-инженеров (`video-fal`, `improve-prompt`) и память (`factory-prompting-canon`).
Собран из исследования (45 правил; 5 столпов промптинга адаптированы под наш пайплайн) + боевых находок завода.

Пайплайн: **WB-фото → [source-prep: Nano clean→stage] → assetBind → [i2v: seedance] → ReelV5.**
Качество ролика определяется НЕ движком (Seedance держит всё), а **чистотой исходника и дисциплиной промпта**.

---

## 0. Главный принцип

- **edit-стадия (Nano/Seedream)** — лаконичный СТРУКТУРНЫЙ промпт `Lock → Change → Scope → Constraints` бьёт
  LLM-простыню. Identity товара держит **дисциплина шаблона** (явный preserve-клозет + one-change-per-turn),
  а НЕ «умность» переписывания. → детерминированный сборщик, без Claude на горячем пути.
- **i2v-стадия (Seedance)** — промпт = **MOTION-СКРИПТ**, не описание сцены. Внешность/свет/цвет уже в стартовом
  кадре; повтор = competing instructions → морфинг. Claude пишет **поверх скелета**, не с нуля.
- **Приоритет источника промпта**: выученный/winner-промпт → Claude-инженер поверх скелета → статический шаблон.

## 1. EDIT (source-prep · Nano Banana / Seedream via fal)

Формула одного вызова:

```
verb-first → Lock (что НЕ двигать) → Change (ОДНО изменение) → Scope (что РЕДАКТИРОВАТЬ нельзя) → Constraints (что edit не должен сломать)
```

- **Lock** — перечислить КОНКРЕТНЫЕ якоря: точная форма/пропорции/цвет/материалы, брендинг, тиснёный/печатный
  логотип и весь текст, фурнитура + категорийные мелочи (см. таблицу). Скрытого preserve-параметра НЕТ — держит
  только дисциплина промпта.
- **Scope** (находка ресёрча Seedream — #1 анти-дрейф рычаг) — ОТДЕЛЬНАЯ дискретная фраза «правь ТОЛЬКО фон/окружение,
  товар не перерисовывай/не двигай/не перекрашивай». Не растворять в Lock — явный Scope режет дрейф лучше всего.
- **ONE CHANGE PER TURN** — `clean` и `stage` это РАЗНЫЕ вызовы (у нас так). Не стекать фон+свет+стиль в один
  промпт — модель молча теряет часть правок.
- **Релайт locked-товара ЗАПРЕЩЁН** — при смене фона разрешать только ambient-свет сцены
  («no new hotspots or harsh relight on the locked product»), но ДОБАВЛЯТЬ контактную тень + рефлекс.
- **Композит = один кадр** — убрать швы, light-wrap, реалистичный масштаб, тень+отражение под новую поверхность.
- **Вертикаль 9:16** с headroom вокруг товара — задавать в Constraints на stage.

## 2. I2V (seedance image-to-video)

Скелет: `[Subject micro-motion] + [ОДИН camera move] + [pace] + короткий preservation-клозет`.

- **НЕ описывать** внешность/свет/цвет/текст/композицию — они уже в кадре.
- **ОДИН camera move** на клип. Стек (orbit+zoom+pan) = jitter + деформация лейбла. Не совмещать движение
  КАМЕРЫ и ОБЪЕКТА — выбрать одно.
- Камера-инструкция в **НАЧАЛЕ**, со словом скорости (slow/smooth/gentle для premium).
- **Детальный/сложный товар** (игрушки, техника, мелкие части) → движение МИНИМАЛЬНОЕ (static + лёгкий push-in).
  Жёсткий простой (флакон, сумка) → можно мягкий камера-мув.
- Лаконично, **~15-25 слов**. Negative (где движок принимает): `no warping, no melting, no extra limbs,
  no flicker, no label distortion, no duplicated product, no jitter`.

## 4. ЧЕГО НЕЛЬЗЯ (частые провалы)

1. ❌ **«remove watermark / logo / text»** в Nano → пре-инференс фильтр вернёт `MALFORMED_FUNCTION_CALL`.
   ✅ Формулировать СОЗИДАТЕЛЬНО: «recreate clean … showing ONLY the …» = реконструкция, не удаление.
   *(Это валило cream-артикулы в ночном батче.)*
2. ❌ Стек камер-мувов (orbit + zoom + pan) в i2v → jitter, деформация лейбла.
3. ❌ Re-describe внешности/света/цвета в i2v → competing instructions → морфинг.
4. ❌ HEX вместо слов для цвета. ✅ «desaturated beige under warm morning side light», палитра 70/20/10.
5. ❌ LLM-простыня на edit. ✅ структурный лаконичный промпт по формуле.
6. ❌ Релайт locked-товара при смене фона.
7. ❌ Низкое разрешение на входе Nano (low-res in → low-quality edit) — заливать hi-res исходник.

## 5. RESET при дрейфе

Если после итераций товар поплыл — **новый тред**: перезалить последний «хороший» кадр / вставить выигравший
промпт ДОСЛОВНО, а не продолжать править испорченный.

## 6. Петля обучения (learning loop)

- `content_assets(disk='prepared').analysis` хранит `category` + `prompt_used` → выигравшие prepared-кадры
  возвращают «золотые» промпты обратно в шаблон (аналогично reelVariants/abRank).
- `video-fal` грундит i2v-инженера на `niche_visual_profiles` + winners/анти-паттерны (`learningHints`).
- ОТК-реген картинки: `improve-prompt route='nano_edit'` усиливает Constraints edit-промпта (не трогая Lock),
  замыкая loop на стадии КАРТИНКИ, а не только видео.
