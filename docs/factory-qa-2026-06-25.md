# Контент-завод — roadmap по починке после текущего прогона (2026-06-25)

Это короткий план на завтра по результатам сегодняшнего ревью `public/inferno/studio.html`, `app/api/factory/products/route.ts`, `app/api/factory/decompose/route.ts` и `lib/factory/graphRun.ts`.

## Что уже поправлено

- В `products` появились реальные сигналы по товару: `realFrames`, `gens`, `hasWinner`, `bestOtk`, `lastOtk`.
- Фильтры товаров стали настоящими кнопками, а не декоративным текстом.
- `+ Новая ниша` честно отключена, вместо ложного CTA.
- `openFormatFork` теперь ведёт в реальные сценарии: видео, статик, карусель.
- ElevenLabs добавлен в студию и в граф сборки.
- В `graphRun` hook/caption/OTK теперь читают текст из нескольких полей, а не только из `onscreen_text`.
- В центре появился рабочий поиск по товарам и нишам.
- Экран балансов показывает последний снимок сразу и не начинает с голой пустоты.
- `graph-run/tick` больше не держится только на `after(...)`.
- Студия показывает `run_id` и warnings вместо старой красной трактовки `otk_fail` как активной политики.
- Добавлен повторяемый стресс-раннер `lib/factory/stressGraphRun.mjs`.

## Что видно на проде прямо сейчас

- На `next start` контрольный рецепт проходит `10/10` без ручного вмешательства.
- При недоступном `video-critic` ролики завершаются с `warning`, а не с блокирующим стопом.
- Локальный `next dev` под длинной серией всё ещё может перезапускаться по памяти, поэтому для baseline лучше использовать `next start`.

## Завтра по приоритету

1. Стабилизировать `video-critic` как quality-signal, не включая fail-closed обратно.
2. Проверить после следующего деплоя, что прод действительно подхватил текущие правки.
3. На экране 02 сделать нормальный safety path: preview / details / явная помощь до `decompose`.
4. На экране 06 ещё полезно добрать поведение старых записей без постера, если они снова всплывут.
5. На экране 07 уже стало лучше, но если нужен совсем гладкий live-режим, можно потом разнести опрос на поэтапный refresh.

## Риск-заметки

- Самый ценный следующий шаг сейчас не новая логика, а подтверждение деплоя.
- Если после деплоя прод всё ещё показывает старый интерфейс, нужно смотреть кеш/сборку, а не код студии.
