# ТЗ: Контент-завод → модульная сборка виральных видео на Shotstack

> Статус: черновик архитектуры, выверенный советом (DMAD, 5 советников + рецензии + девилз-адвокат).
> Цель документа: отдать Claude Design на проектирование, затем реализовывать фазами.
> Дата: 2026-06-20. Источник: фоновый сбор (3 агента) + council-review.

---

## 0. Главный вывод совета (читать первым)

**Направление верное — модульная сборка (видео = граф блоков [HOOK]+[SCENE×N]+[PAYOFF]+[CAPTIONS]+[MUSIC]+[LOOP], реальная съёмка = хребет, Shotstack = дефолтный финал). Владелец прав: одиночный клип/карусель — структурно мёртвая категория.**

**НО:** не строить весь node-граф / Shotstack Templates / per-slot A/B-бандит вслепую. Это over-scope и регресс рабочей системы (base rate переписок модульных движков на работающих системах — провал 60%+).

**Заход — «ходячий скелет» + фазы:** тонкий вертикальный срез, который ОДНОВРЕМЕННО (а) де-рискует «тихих убийц» и (б) даёт первый постимый ролик, снимая chicken-and-egg «нет сигнала для обучения». Полная модульность — фаза 2, после доказанного скелета и контура постинга.

**Глубочайшая слепая зона (вскрыли рецензенты):** НЕТ контура дистрибуции/постинга → нет сигнала. Цель «залетать», но нигде не определено: куда постим, с какой частотой, как ловим метрики (views/watch-rate/CTR на карточку). Без этого winners / A/B / бандит / «петля обучения» — пустые. **Это приоритетнее графа сборки.**

## 2. Целевое видение (направление — сохраняем)

Видео = **граф composable-нод**, не один проход AI/слайдшоу.

**Каноническая нода `Block`:**
```
Block {
  id, slot: hook|scene|payoff|transition|caption|music|effect|loop,
  role, asset_url, asset_type: real|ai|utility,
  emotion: shock|curiosity|calm|flex,
  duration_sec, beat_suitable: bool,
  in:{requires:[]}, out:{provides:[]}, tags[]
}
```
Эта нода — ЕДИНЫЙ язык: `viral_videos.beat_structure` ↔ `niche_playbooks.winning_formats.beats[]` ↔ Shotstack `AssemblyClip[]` сводятся к ней.

**Слоты и I/O:**
- `HOOK` — in={}, out={attention}; визуальный паттерн-брейк (hard-cut/snap-zoom) в первом кадре, окно решения 1-1.5с. Без HOOK граф невалиден.
- `SCENE×N` — in={attention}, out={context}; **реальный товар-клип/фото = хребет**, смена кадра 1.5-2.5с, длительность из `duration_sec`, gap-free кумулятивная раскладка, emotion-arc shock→curiosity→build.
- `PAYOFF` — in={context}, out={resolution}; ревил/flex/CTA за 3-5с до конца (rewatch-окно).
- `CAPTION` — глобальный слот, нативный Shotstack text-track, RU Noto Sans Cyrillic, ≤7 слов первый сабтайтл.
- `MUSIC` — глобальный аудио-слот, sound_id из корпуса (бит-драйвер; пока фикс-каденс без mp3).
- `EFFECT` / `LOOP` — задел (speed-ramp/zoom; последний кадр→первый seamless rewatch).

**Принципы:** реальная съёмка (Яндекс-диск) = обязательный хребет; AI (Seedance/Kling) + карусель = ПОСТАВЩИКИ тегированных блоков в библиотеку, не финал. Корпус Virlo = ИСПОЛНЯЕМЫЙ рецепт раскладки слотов (`structure_by_seconds` → секундная сетка). Самообучение на УРОВНЕ БЛОКОВ. Единый ключ — `nicheFromArticle`. Единый серверный конвейер (очередь), браузер — только createJob + прогресс.

## 3. ФАЗЫ (порядок — по вердикту совета, НЕ «всё сразу»)

### ФАЗА 0 — ДЕ-РИСК УБИЙЦ (неделя 1, дёшево, ДО кода). Гейт всего.
- **0.1 🔴 Живой смоук RU-шрифта на Shotstack `stage`** (watermark, бесплатно): реальное фото с диска + русский хук-текст + саб → mp4. Глазами: кириллица рисуется или tofu? Выглядит как монтаж? **Если tofu — вся стратегия на паузе, разбираемся с text/title/html-asset или другим движком.** Это $0, 1 час, разблокирует/убивает всё.
- **0.2 Аудит реальной съёмки по нишам:** инвентаризация диска × `nicheFromArticle`. **Если у 30%+ ниш <5 клипов — это проблема КОНТЕНТА/СЪЁМКИ, не движка** (завод упрётся в ручное наполнение, не в код). Решение supply: поток съёмок / микро-креаторы под модульные кадры (₽500-1k/кадр по нише+хуку) — аналог TikTok Spark Ads / Smartly.io.
- **0.3 Цена/лимиты:** gap-free раскладка без дыр; стоимость 1 рендера; concurrency 8; нужен ли семафор на compose.

**Критерий выхода из Фазы 0:** (1) RU-текст читается; (2) ≥2 ниши с ≥5 клипами; (3) понятна цена рендера.

### ФАЗА 1 — ХОДЯЧИЙ СКЕЛЕТ + ПОСТИНГ-СИГНАЛ (снимает chicken-and-egg)
Цель: **первый ролик, который владелец реально запостит**, и контур, ловящий сигнал.
- **1.1 Бэкфилл тегов (предусловие сборки):** `disk-source` → asset_type=real + `duration_sec` (ffprobe) + role (эвристика: scene/broll); `gen-save` → asset_type=ai + role + otk-score; sharp-карусель → utility. Без наполненной библиотеки assemble не запускать.
- **1.2 Тонкий срез сборки (1 ниша, где съёмка ЕСТЬ):** реальные кадры + хук-текст + сабы + смена кадра ~2с → Shotstack → mp4. Минимальный assemble (ещё НЕ полный граф-резолвер): hook→scene×N→payoff, gap-free из `duration_sec`, нативный text-track. ОТК на кадрах.
- **1.3 🔴 Контур постинга→сигнала (самое важное):** ручной/полу-авто постинг одобренного → лог `views/watch_rate/CTR_на_карточку` в `factory_assemblies` → в `winners`. БЕЗ этого петля обучения мертва. (Минимум: поле метрик + ручной ввод, как ниже.)

**Критерий выхода из Фазы 1:** владелец запостил ≥3 собранных ролика и есть первые метрики.

### ФАЗА 2 — ПОЛНАЯ МОДУЛЬНОСТЬ (только после доказанного скелета + сигнала)
- node-граф `Block` как единый язык; `produce` → детерминированный роутер по факту тегированной библиотеки (LLM только для креативной структуры формата).
- `assemble` → ролевой граф-резолвер (выбор Block по role/asset_type/emotion/duration/beat_suitable + emotion-arc + секундная раскладка).
- Shotstack **Templates+merge**: один шаблон-формат на winning_format ниши, «поменять блок» = подмена merge-поля, **per-slot A/B** = два merge-набора на template_id. `buildEdit` → fallback для ниш без шаблона.
- `factory_assemblies` += `template_id` + `slots jsonb {role→{block_id,start,length,effects}}` + `views` + `is_winner`.
- `winners` пишет ВЫИГРАВШИЙ слот-граф; `variations` → мутация ОДНОГО слота при фиксированных остальных (per-slot A/B, бандит-выбор по otk→views).
- Слить конвейеры: браузерный `_genIdea/runFull` → createJob + status-прогресс.

## 4. Миграция (keep / rewrite / kill)

**KEEP** (фундамент — не трогать):
- self-chaining очередь `lib/factory/jobs.ts` + `jobs/tick` (lease, renderCount/composeCount≤3, гарды от двойной оплаты) — единственный конвейер после слияния.
- Виральный корпус Virlo (`viral_videos.beat_structure/hook_text/virality_score`, `viral_hooks` viability 1-5, `orbit_searches`, `niche_monitors`, `niche_playbooks.structure_by_seconds/render_role`) + `hook-judge` + анти-слоп ОТК (`video-critic`/`rubric`).
- `disk-source` (реальная съёмка по артикулу/цвету) + `content_assets` как библиотека блоков.
- `factory_assemblies` + `gen-save` (Storage-банк, дедуп по url).
- `nicheFromArticle` как единый ключ ниши.
- `shotstackSubmit/Status` (изоморфны falVideoSubmit/Status — ложатся на очередь без изменений); изоляция Edit-схемы в `buildEdit()`.

**REWRITE:**
- `produce/route.ts`: LLM-угадайка → детерминированный роутер по факту тегированной библиотеки. *(Фаза 2)*
- `assemble/route.ts`: dumb-конкатенация `slice(4)` → ролевой граф-резолвер. *(Фаза 1 тонко → Фаза 2 полно)*
- `lib/factory/shotstack.ts`: GAP-FREE раскладка (кумулятивный start из `duration_sec`); `quantizeToBeats` ТОЛЬКО при реальном audioUrl+bpm; нативный text-track как единственный путь субтитров; Templates+merge (`buildEdit`→fallback). *(text-track — Фаза 1; Templates — Фаза 2)*
- `jobs/tick runStep`: финал ВСЕГДА через assemble (сборка=дефолт); одиночные генераторы пишут блок в библиотеку; откат assemble→scenario → wait/honest-fail; ОТК ДО Shotstack; `single=true` для исключений (talking-head UGC / 1 идеальный реальный клип / тест хука). *(Фаза 2; в Фазе 1 — узкий happy-path)*
- `winners/route.ts`: писать ВЫИГРАВШИЙ слот-рецепт (не только хук). *(Фаза 2)*
- Кокпит `patrick.html`: ключ playbook по `nicheFromArticle` (не `_brandOf`); `_genIdea/runFull` → createJob + status. *(Фаза 2)*
- Писатели тегов content_assets: бэкфилл asset_type/role/emotion/duration_sec/beat_suitable при индексации. *(Фаза 1 — предусловие)*

**KILL:**
- Браузерный синхронный рендер-поллинг (`runFull→_genIdea` while+setTimeout до 6 мин) как дефолт.
- Карусель из 1 фото как самостоятельный финал (max — utility-блок/fallback).
- `ai_generation_ref` (i2v целым роликом) как штатный финал (только короткий [SCENE]-акцент под флагом single).
- `localStorage.cf_playbooks` keyed by `_brandOf` (или → тонкий read-кеш niche_playbooks, источник правды БД).
- fal `/overlay` compose-шаг (захардкоженные 5с) — поглощается нативным Shotstack caption-track.
- `quantizeToBeats` без audioUrl + `fixedBeatGrid(120BPM)` как «рычаг» (no-op без mp3, честно демоут).

## 5. Открытые вопросы (решения совета)

| Вопрос | Решение совета |
|--------|----------------|
| **A. RU-шрифты Shotstack** | НЕ предполагать — **живой смоук Фаза 0.1 ДО любого кода.** Бинарный риск, гейт всего. |
| **B. Templates vs императивный buildEdit** | Императивный buildEdit (gap-free) в Фазе 1; Shotstack Templates+merge — Фаза 2 (когда формат-победитель стабилен). Привязать версию шаблона к версии плейбука. |
| **C. Реальная съёмка = боттлнек** | Аудит Фаза 0.2. Если supply тонкий — это проблема контента, решается потоком съёмок/микро-креаторами (модульные кадры по нише+хуку), а не кодом. |
| **D. Бит-синк/звук без mp3** | Фикс-каденс честно демоутнут (не «рычаг»). MUSIC/LOOP — фаза после реального mp3-источника (yt-dlp по url видео / сторонний sound-провайдер). До тех пор звук — текстовая инструкция при постинге. |
| **E. Цена Shotstack** | ОТК ДО сборки (судить блоки, не финал) + семафор ≤8 на compose + не перерендеривать всю сборку из-за одного блока. План ($39/мес vs pay-as-you-go) — посчитать по факту объёма после Фазы 1. |
| **F. Поэтапность** | За флагом, фазами (см. §3). Сначала теги+смоук, потом узкий срез, потом разворот дефолта. Не ломать зелёный билд. |
| **G. Shotstack vs альтернативы** | Shotstack ОК для Фаз 0-1 (submit→poll ложится на очередь). EFFECTS/speed-ramp/loop вне текущей схемы — если нужны нативно и Shotstack не тянет, резерв JSON2Video/Remotion+Lambda оценить в Фазе 2, не раньше. |

## 6. Риски (с вердикта)

1. **RU-tofu** — кириллица не рисуется → ролик-пустышка проходит ОТК на кадрах без текста. Блокер. → Фаза 0.1.
2. **Пустая библиотека = стоп завода** — если сделать сборку дефолтом ДО наполнения тегов/реальных блоков, джобы упадут в wait. → Фаза 1.1 предусловие.
3. **Цена × A/B нелинейно** — per-slot A/B множит рендеры; без ОТК-до-сборки и семафора — двойная оплата. → §5.E.
4. **Бит-синк декоративен без mp3** — «собрали LEGO, а не залетает». → честный демоут, §5.D.
5. **Большая переписка = регресс** — base rate 60%+. → фазы за флагом.
6. **Реальная съёмка = боттлнек пропускной** — объём 20+/нед упрётся в наполнение диска. → supply-решение, §5.C.
7. **Нет постинг-сигнала = обучение слепое** — без метрик winners/A/B пусты. → Фаза 1.3, приоритет.

## 7. Первый шаг (один, сегодня)

**Живой смоук-рендер на Shotstack `stage`:** реальное фото с диска + русский хук-текст («Вы неправильно используете…») + саб → mp4. Посмотреть: кириллица или tofu, выглядит ли как монтаж. $0, 1 час. Разблокирует или убивает всю стратегию — и определяет, идём ли вообще на Shotstack.

**Как проверить успех направления:** (1) RU-текст читается; (2) ≥2 ниши с ≥5 клипами на диске; (3) первый собранный ролик владелец готов запостить; (4) через 2 недели есть ≥3 запощенных ролика с метриками. Тревога: нет постимого ролика за 2 недели → ты не в фазе сборки, а в проблеме контента/съёмки.
