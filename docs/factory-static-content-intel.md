# Статичный контент: разведка рынка + стратегия (РФ-товарка)

Синтез большой разведки (Pinterest + статика соцсетей, 2026) под линию статики завода.
Тактика/правила — в **`docs/factory-pin-canon.md`**. Этот док — СТРАТЕГИЯ и вердикт «куда вести».

## Executive-вердикт
**Не строить движок «вокруг Pinterest».** Для РФ-товарки Pinterest — почти-бесплатный бонус-канал, а не ядро.
Строить **«одно дизайн-намерение → N экспортов»** и якорить на **инфографику карточки WB/Ozon (3:4)** — это первый продукт.

**Почему Pinterest не ядро для РФ (доказательно):**
- Охват РФ крошечный и падает: −20-29% (фев-март 2026, brandanalytics). Гиганты РФ — Telegram ~96M, VK ~95M, Dzen ~66M MAU. РФ Pinterest MAU не раскрыт → размер аудитории по сути неизвестен.
- РФ-селлеру **недоступны** Pinterest Ads / каталог / Verified Merchant / Rich Pins / региональные Trends → только органика, без платного рычага.
- Органика тонкая и медленная: кейс ~2000 кликов/мес → 4-6 продаж, первый трафик через 3-4 мес (vc.ru).
- Платформенный риск: штрафы (6M₽ дек-2025, 3.5M₽ окт-2024), **нет в РФ-whitelist** при веерных отключениях мобильного инета (>половины регионов), возможен бан. При отключениях Pinterest гаснет, VK/Yandex/маркетплейсы работают.
- **AI-пины даун-ранкуются/лейблятся** Pinterest'ом — прямой риск код/AI-рендеру именно на Pinterest.

**Где ROI статики реально (РФ, по убыванию):**
1. **Карточка WB/Ozon (3:4)** — +30-50% конверсии на УЖЕ бесплатном трафике маркетплейса, ноль платформенного риска, 71% смотрят только первые 5 слайдов. **Первый продукт.**
2. **VK shoppable / шопс** — крупнейшая досягаемая визуально-коммерч. площадка РФ (~95M MAU, чек-аут в ленте, не гаснет при отключениях).
3. **Telegram deeplink-карточка** — #1 канал РФ по MAU, дешёвый CPV (0.5-5₽/просмотр); deeplink обязателен (иначе конверсия ↓2-3×).
4. **Pinterest 2:3 evergreen-пин** — дешёвый бонус (женская/эстетная аудитория, медленный ручеёк, риск троттла).
5. Yandex/IG-grey — опционально.

**Итог:** маржинальная стоимость код-рендера ≈ 0 → авто-публикация в Pinterest = бесплатный апсайд. Но не давать Pinterest диктовать дизайн-систему и мерить успех по **заказам через deeplink**, не по saves (в РФ — vanity).

## Growth-loop
Толстый хвост (топ-1% пинов >50% показов) → **fresh-variant multiplier** (volume распознаваемо-разных вариантов + ruthless winner-detection) · fresh pins ≠ repins (дубли суппрессятся) · ранжирование: домен+пин-качество+авторитет+релевантность, читается title+desc+**ALT**+board+OCR текста на картинке · evergreen ~13 мес · winner-loop по **заказам через deeplink**.

## Пробелы / что валидировать (порядок)
1. **Аплифт карточки WB/Ozon на НАШИХ SKU** — держится ли +30-50%? A/B старая карточка vs инфографика (load-bearing claim).
2. **Deeplink/атрибуция** — мультилинк-сервис сохраняет WB/Ozon-атрибуцию (иначе измерение по заказам рушится).
3. **Satori vs Remotion** на наших шаблонах (no-grid/no-cover/no-variable-fonts ограничения Satori; Remotion=Chromium даёт полный CSS — мы уже на Remotion).
4. **Collage 73/87/81%** — один источник, 1 A/B → не догма, проверить своим A/B по нише.
5. **РФ Pinterest спад −20-27% и AU-даунранк** — инференс/один источник; малый live-тест AI-finish vs photo-finish перед ставками.
