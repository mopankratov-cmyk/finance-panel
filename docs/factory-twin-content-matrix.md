# Матрица контента из товарных твинов — Reels/Wibes + Pinterest

> Итог исследования 04.07.2026 (4 параллельных трека: форматы вертикального видео, Pinterest для fashion-екома, мировая практика AI-генерации из packshot'а, инвентаризация нашего кода). Канонический вывод: **главный козырь завода — цветовые линейки с идентичной геометрией** (после перекраски из эталона 04.07 у нас 4 модели × 8–9 цветов, где каждый пиксель соответствует), и почти весь высокоэффективный контент строится на них без единого риска галлюцинаций.

## Ключевые факты из исследования

**Wibes (основной канал видео):**
- ~60% смотрят без звука → текстовые плашки обязательны, УТП читается без аудио
- Ранжирование: досмотр >60% + скорость реакции (лайк/коммент ≤5с) → форматы с вопросом («пиши номер цвета») кормят алгоритм
- 15–30с, хук ≤2с, артикул на экране со 2-й секунды, до 20 SKU-тегов на видео
- Органика скромная (сотни–тысячи просмотров) → юнит-экономика должна сходиться при малых просмотрах = дешёвые packshot-форматы в приоритете

**Pinterest (новый канал, органика):**
- РФ НЕ заблокирован (весна 2026), ~30 млн аудитория, №1 в мире по открытиям приложения, 48–52% — 18–24, фэшн — топ-категория. Но: замедление с фев-мар 2026 (−20–27% показов), реклама/каталоги/Trends для РФ отключены → **чисто органический SEO-канал**
- Ссылки на wildberries.ru работают; паттерн: пин → конкретная карточка артикула + UTM (WB ещё и режет комиссию за внешний трафик)
- Рабочая лошадка: статика 2:3 (1000×1500) — +67% к вовлечению vs квадрат; видео-пины 6–15с
- **Коллажи/палитры сейчас — формат №1 по сохранениям (2× vs обычный продуктовый пин)** — а палитры из 9 идентичных цветов никто дешевле нас не сделает
- Сезонность: контент за 45–90 дней до спроса → пуховики пинить с августа, ветровки на весну — с января
- SEO: ключ в первых 40 знаках тайтла, описание 220–232 знака с ценой и CTA, alt-text (+123% переходов), доски категорий + доски намерений («Капсульный гардероб», «С чем носить пуховик»), 3–5 пинов/день

**Правила безопасности генерации (из практики + наши мандаты):**
- Твин — только фас; спину/бок НЕ выдумывать (это и правило владельца, и комплаенс WB: искажение товара = нарушение + возвраты)
- Вайтлист движений для i2v: наезд (push-in), статичная камера + ветер, параллакс, macro rack focus. **Бан: орбита >30–45°, 360°, развороты, морфы**
- Сцены — только «cut-and-composite»: фон меняем, пиксели куртки не перерисовываем
- Цветовые свитчи — детерминированная склейка (ffmpeg xfade / hard cuts), НЕ AI-морфы: геометрия гарантирована математически

## Что уже есть в коде (инвентаризация)

**Гэпы (по важности):** (1) цветовой свитч — код-роут (пилот собран скриптом, надо заводом); (2) static-generate не читает twin store (глюе ~20 строк); (3) fashn/tryon объявлен, но не обвязан — нужен для стайлинга; (4) publish — только леджер, постинг ручной; normalizeDistributionPlatform не знает wibes (известный баг).
