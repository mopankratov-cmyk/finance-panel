# V3 Завод — ТЗ обучаемого автопилота («тренажёр завода»)

**Дата:** 2026-06-21 · **Статус:** требования собираются (владелец накидывает) → дизайн за советом → build-спек.
**Связь:** капстон над [factory-v3-roadmap.md](factory-v3-roadmap.md) (стоит на закрытии V1/V3/V4/V7/V11/V20). Память: `factory-v3-roadmap`.

## Видение (дословно владельца)

> «Штука, которая поможет научить контент-завод быстрее: запустил — ушёл на сутки, она сделала 100 видео, ко мне на проверку дошли только готовые, я дал обратку, всё записалось в память и **обновило навыки** — и так через неделю получим очень крутой завод.»

Это **обучаемый автопилот под экспертным надзором** (НЕ автоген-на-кнопку): человек-эксперт в петле, его обратка реально меняет поведение следующего батча и **компаундит**.

## Требования (накидано владельцем — все подтверждены ✅, с нюансами)

**R1 · Автопилот-батч.** Запустил → фоном за ночь делает N (≈100) видео. ✅ Переиспользуем server-side execution runner `graph-run` (вкладка не нужна, уже есть).

**R2 · Фильтр ПЕРЕД человеком.** К владельцу доходят **только готовые** — брак отсеян. ✅ Это ОТК-петля + артефакт-гейт (V3/V4). Иначе утром 100 слопов и ревью убьёт сутки.

**R3 · Артефакт-ревью на генерации (НОВОЕ, явно).** На каждой генерации — vision-проверка кадров на **сломанные артефакты**: уанкэни, текст-блид с WB-карточек, кривые руки/пальцы, морфинг/плавящиеся края, битый липсинк → брак **авто-перегенерится**, дальше не идёт. Цель: «генерация выдалась идеально». ✅
- ⚠️ Нюанс: **липсинк по статичным кадрам не судится** (урок HeyGen-аватаров: критик смотрит замороженные кадры, а брак липсинка — в движении/звуке). Для липсинка нужен motion/audio-чек, а не только кадры. Уанкэни/руки/текст-блид/морфинг — кадрами ловятся.

**R4 · Мульти-вариант на одно ТЗ (НОВОЕ).** На каждый бриф/рецепт генерить **не один, а N вариантов** (разные хуки/движки/углы/актёр-или-без) → показывать рядом → выбирать лучший; остальные в A/B-память. ✅ Обобщение хук-турнира (V9) на целый ролик.
- **Решено владельцем: 3 варианта/ТЗ** (пока). Косты ×3 (3 × 100 ТЗ = 300 рендеров/ночь ≈ $150–360). Решается бюджет-капом (V11) + артефакт/ОТК-фильтром ДО показа (сравниваешь только выживших), либо меньше базовых ТЗ × 3 варианта.

**R5 · Telegram + голосовое ревью (НОВОЕ).** Бот шлёт владельцу видео; он отвечает **голосом** «ок / не ок / что не так» → ASR-транскрипт → LLM разбирает в структурную обратку (вердикт + причины + какая ось/нода провалилась) → skills-updater. Async, с телефона — правильный канал для «ушёл на сутки». ✅
- ⚠️ Нюанс: голос богаче свайпа (можно «хук слабый, но монтаж ок»). ASR — **fal-whisper** (переиспользует `FAL_KEY`, новый ключ не нужен).
- **Контракт ENV (отдельный бот завода, НЕ общий TELEGRAM_BOT_TOKEN — тот занят другим):**
  - `FACTORY_TG_BOT_TOKEN` — токен заводского бота (владелец создаёт в @BotFather, кладёт в Vercel; код читает из env, в гит не пишем).
  - `FACTORY_TG_CHAT_ID` — chat_id владельца (allow-list: бот слушает/шлёт только ему). Снимается из первого `/start`.
  - Webhook: `POST /api/factory/telegram` (свой эндпоинт; апдейты заводского бота идут только сюда — разделение от другого бота гарантировано Telegram'ом).

**R6 · Обратка → память → навыки.** Обратка **записывается и обновляет навыки**: дельты в `viral_hooks` / `niche_playbooks` / `brandProfiles` / калибровку `rubric` / few-shot-примеры промптов / `winner_learnings`. Следующий батч **читает** обновлённые навыки → компаунд. ✅ (retrieval/few-shot, НЕ дообучение модели). Это V7 + новый skills-updater.

**R7 · Гард-рейлы против вырождения (заложить в дизайн).** Чтобы за неделю завод **стал круче, а не переобучился** под вкус эксперта/робота и не выродился в эхо-камеру: разнообразие углов, exploration vs exploitation, периодическая сверка с Virlo-рынком, измеримый критерий «стало лучше». ⚠️ Без реальных метрик постинга (V5) сигнал = вкус эксперта + робот — это ценно, но требует гард-рейлов.

## Канонический стек генерации — КАК делать «идеально» (источник: [openreels-pipeline.md](openreels-pipeline.md), опыт v9)

Это **проверенный лучший путь** к качеству — автопилот собирает ролики ИМЕННО так:

**Цепочка openreels (data-driven, server-side на Vercel):**
`бриф(JSON) → ElevenLabs v3 (RU точный текст) → Creatify lipsyncs (audio=своё аудио, не TTS) → Seedance 2 i2v (реальные фото моделей) → Remotion ReelV5 (параметризованный пропсами) → артефакт-гейт → ОТК-петля → варианты из Virlo-углов → обучение`

**Главное правило:** точный русский = ElevenLabs → Creatify lipsync под СВОЙ аудио. Единственный надёжный путь (верные слова + живой голос + речь на весь ролик).

**🚫 Анти-паттерны (вшить в роутинг/гейт):**
- НЕ Veo для русской речи (коверкает слова, «скушидики мек») — только визуал/энергия.
- НЕ детский AI-актёр (миноры запрещены) → реальные кадры детей (Seedance) + детский TTS, без говорящей головы.
- НЕ карточки WB с диска как футаж (вшитый текст = слоп) → реальные фото моделей.
- Creatify-актёр НЕ держит товар → точность товара держать Seedance-кадрами/CTA.

**Новые зависимости/интеграции (сверх карты), нужны для openreels:**
- **ElevenLabs** — `ELEVENLABS_API_KEY` + адаптер `lib/factory/elevenlabs.ts` (через Palmier MCP на Vercel server-side НЕ пойдёт — нужен прямой API).
- **Аудио-хостинг для Creatify** — НЕ tmpfiles.org (умирают), а Supabase Storage через `media-store` → public URL → `audio` в Creatify lipsync.
- **Remotion-рендер как роут** — параметризовать `ReelV5.tsx` пропсами (actorUrl/clips[]/captions[]/brand/cta) + headless-рендер через `@remotion/lambda` (это РЕАЛЬНАЯ AWS-инфра — совет был прав про цену; но путь принят, т.к. даёт лучший результат). Флаг отката на Shotstack-сборку.
- **Whisper (fal) двойного назначения** — (1) word-timestamps для синка капшенов VO; (2) транскрипт голос-ревью оператора (R5). Один провайдер.
- **Слой пресетов/бренд-кита** — RU-голоса ElevenLabs, курированные молодые RU-дружелюбные Creatify-персоны (id), кириллические шрифты (Montserrat/Unbounded), бренд-цвета/CTA, бан-фразы (DEAI_FILTERS), хэштег-наборы по нишам. (расширяет V14).

**Инфра (из openreels-pipeline.md §5):** гонять на Vercel (РФ-локалка рубит SSL/аудио-fetch); цена WB из БД `wb_orders` (не из локалки); Creatify-ключи Sensitive (vercel pull пустой — рантайм подставляет).

## Поток (предварительно)

```
[Планировщик батча]   ниши×товары×углы из Virlo-корпуса + N вариантов/ТЗ + бюджет-кап
  → [graph-run execution runner]   генерит N×варианты фоном
  → [Артефакт-гейт (R3)]       vision-чек кадров → брак авто-реген
  → [ОТК-рубрика (V3/V4)]       <7 → improve-prompt + реген (бюджет MAX_RENDERS)
  → [Telegram-бот (R5)]         утром: шлёт выживших (варианты рядом), владелец наговаривает
  → [ASR + LLM-парсер]          голос → структурная обратка
  → [Skills-updater (R6)]       дельты в навыки
  → [next батч читает]          компаунд (R7 гард-рейлы)
```

## Зависимости от дорожной карты

Новое сверх карты: планировщик батча, Telegram-бот+ASR-парсер, skills-updater, артефакт-гейт как отдельная стадия.
