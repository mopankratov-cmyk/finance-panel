## 2. Точный пайплайн v9 (шаг за шагом)

1. **Товар** → `TT04101`, WB nmId `366846266` (вытащил с фото-карточек на диске). Спеки: дальность 8 м, автоочередь, имитация звука, свечение, бак 207 мл. ⚠️ Розничную цену WB подтвердить не смог (сеть рубит) → цифру цены из ролика убрал.
2. **Virlo Orbit** по ключам водных пистолетов → победный угол **«не показывай детям»** (взрослый угол, высший engagement), спек-дамп работает, звук — **весёлый летний** (не трап), хэштеги `#childrentoys #electricwatergun #waterguntoy #tiktokshop #summerfun #fyp`.
3. **Сценарий** (взрослый/смешной угол) по `standard.ts` (CONTENT_STANDARD + HOOK_FORMULAS, без бан-фраз DEAI_FILTERS).
4. **Озвучка** → ElevenLabs v3 (voice Roger) читает ТОЧНЫЙ текст → mp3.
5. **Хостинг** → залил mp3 на tmpfiles → direct URL.
6. **Актёр** → Creatify `lipsyncs` (персона **Ivan** `09f13a45-…`, молодой) + `audio`=наш URL → актёр говорит наш точный русский, на всю длину.
7. **Клипы** → Seedance 2 i2v с реальных фото модели (мальчик/девочка с УЗИ) + продуктовый макро+залп (Seedance reference от фото товара).
8. **Сборка** (`remotion/ReelV5.tsx`): база-актёр (аудио-спайн, `playbackRate 1.2` для энергии) + Seedance-врезки поверх (на спеках) + кинетик-капшены (Montserrat, обводка, поп по словам, акцент-цвет) + тёплый грейд (`soft-light` overlay связывает «3 мира») + виньетка + брендовый CTA-эндкард + летний трек (громкость функцией: тихо под голосом → дроп на монтаже).
9. **Рендер** → `remotion render remotion/index.ts ReelV5 out.mp4` (headless).
10. **ОТК** → импорт в `inspect_media` (кадры) → `scoreRubric` → 3 прохода критики → фиксы → пере-рендер.

## 3. Что РАБОТАЕТ (закладывать в завод)

- **Точный RU-текст = ElevenLabs → Creatify lipsync под СВОЁ аудио** (`audio`=URL в `/lipsyncs/`). Единственный надёжный путь к верным русским словам + живому голосу + непрерывной речи на весь ролик.
- **Реальное фото модели → Seedance i2v** даёт живые кадры с людьми (человек настоящий, Seedance добавляет движение). Лучше кропа карточек.
- **Remotion как компоновщик** — полный контроль (любой шрифт, грейд, кинетик, переходы, бренд), версии = правки кода, headless, облачно-рендерится (lambda).
- **Virlo для угла/звука** — заземляет сценарий на реальные виралы, а не на догадки. Угол «не показывай детям» и «дети в восторге» — рабочие в нише игрушек.
- **Единый тёплый грейд** поверх всех сцен (`mixBlendMode: soft-light`) — связывает разные источники (актёр/продукт/дети) в один мир.
- **ОТК по `scoreRubric`** + 3-проходная критика ловит реальные дыры (не штампует).

## 4. Что НЕ работает / ограничения (проектировать с учётом)

- **Veo 3.1 по-русски НЕНАДЁЖЕН** — импровизирует/коверкает слова (у одной персоны вышла полная тарабарщина «скушидики мек»). Использовать Veo только для визуала/энергии или НЕ-русской речи, не для точного RU-диалога.
- **Детских AI-аватаров НЕТ** (Creatify/HeyGen/Higgsfield блокируют миноров юридически). «Детский» вайб — через реальные кадры детей (Seedance) + детский TTS-голос, без говорящей головы ребёнка.
- **Creatify-актёр не держит наш товар** — аватары не берут произвольные пропсы. Точность товара держать Seedance-кадрами/CTA. (Veo даёт ствол в руке, но ВЫДУМАННЫЙ.)
- **Синк капшенов к RU-речи — приблизительный** (нет word-timestamps). Для точного — добавить Whisper-ASR (word-level).
- **Потолок аутентичности — AI-футаж.** Реальная телефонная съёмка человека-с-товаром пробьёт его. Заложить в бриф «слот реального футажа».
- **На диске — карточки-инфографики WB (вшитый текст), не сырьё.** Брать оттуда реальные фото моделей, не продуктовые карточки (иначе слоп).
- **Higgsfield UGC** — потенциально живее (Soul 2.0 + Seedance нативная речь), но веб-студия без API (headless не прогнать) + RU под вопросом. Только ручной A/B.

## 5. Инфра-гочи (важно для завода)

- **Сеть из РФ-локалки/песочницы рубит SSL** на крупных скачиваниях и fetch аудио-результатов (TLS / ECONNRESET). Лечение: докачка с резюмом (`-C -`), ретраи, **устойчивые поллеры с try/catch** (`scripts/creatify-poll.mjs`). **В заводе на Vercel этой проблемы нет** — там и гонять.
- **Creatify-ключи в Vercel помечены `Sensitive`** = write-only: `vercel env pull` отдаёт их ПУСТЫМИ. Для локального запуска нужны реальные значения в `.env.local`; в проде их подставляет рантайм Vercel. ⚠️ Ключи, что вставлялись в чат, **перевыпустить**.
- **Цена WB** из локалки не тянется (гео) — брать из БД (`wb_orders` nmId→цена) на стороне завода.
- **Кредиты/стоимость на ролик**: Creatify (актёр) + Seedance (клипы) + ElevenLabs (голос) [+ Veo]. Бюджетировать на товар/вариант.

## 6. Рекомендация: как собрать `openreels` в заводе

**Где гонять:** server-side на Vercel (ключи + нормальная сеть там). Весь стек — облачный по API (ElevenLabs + Creatify + Seedance-fal + Remotion-lambda).

**Стадии (data-driven):**
1. **Бриф (JSON):** товар (nmId/спеки/цена из WB+seed) + угол/звук из Virlo-корпуса + сценарий (LLM по `standard.ts`/`DEAI_FILTERS`) + реальные фото-рефы (диск) + бренд-кит.
2. **Ассеты:** ElevenLabs VO (точный текст) → Creatify lipsync (персона из курированного набора молодых/RU-дружелюбных) → Seedance i2v с реальных фото → музыка (fun-summer).
3. **Гейт артефактов:** vision-проверка каждого клипа (уанкэни/текст-блид/кривые руки/битый липсинк) → авто-реген плохого.
4. **Сборка:** `remotion render` (lambda) по параметризованному `ReelV5`-шаблону (пропсы из брифа).
5. **ОТК-петля:** `scoreRubric` → если <7, LLM-критик (как 3 прохода) → авто-фиксы → пере-рендер до ≥7.
6. **Варианты/A-B:** N углов из Virlo-корпуса × персона → ОТК-ранжирование → топ.
7. **Обучение:** лог ОТК + реальные просмотры опубликованного (Virlo-tracking) → система предпочитает залетающие углы/персоны/шаблоны.

**Пресеты заложить:** RU-голоса ElevenLabs, курированные молодые Creatify-персоны (id), кириллические шрифты, бренд-цвета/CTA, бан-фразы, хэштег-наборы по нишам.
