## Required test environments

1. Unit tests: pure policy, env builder, context propagation, ownership, state transitions, redaction.
2. Integration tests: isolated temporary HOME, synthetic auth stores, mock providers/MCP, SQLite/Postgres test DB, no external network.
3. Security tests: distinct UID/container/ACL principals, mount and egress denial, hostile task/MCP content.
4. Recovery tests: process death, stale lease, restart, retry, reclaim, revoked grant, partially written artifact.
5. Cockpit browser tests: BFF-only network assertions and credential sentinel scan.
6. Canary: future phase only, after all offline gates pass and owner explicitly authorizes it.

## Release gate

Implementation cannot be considered deployable until every critical test above is automated, fails against the unsafe fixture where applicable, passes against the candidate, emits sanitized evidence, and has an assigned owner and rollback procedure.
