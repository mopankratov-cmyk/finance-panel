## 1. Цель и готовое поведение
На главной (`/`) панель «Что требует внимания» (топ-5 срочных сигналов) становится сворачиваемой. По умолчанию — СВЁРНУТА; клик по заголовку разворачивает/сворачивает список; состояние помнится между перезагрузками (localStorage).
Наблюдаемые эффекты:
- При заходе на `/` (когда есть непрочитанные инсайты) панель показывает только кликабельный заголовок «Что требует внимания · N» с шевроном; сам список из 5 строк скрыт.
- Клик по заголовку разворачивает список и переворачивает шеврон.
- После перезагрузки (F5) состояние сохраняется.
- Ссылка «Все инсайты →» продолжает вести на `/agent` (не сворачивает панель).

## 2. Решения приняты за тебя (не переспрашивай)
- По умолчанию панель **СВЁРНУТА** (`useState(true)`), как просил владелец.
- Persist — через `localStorage`, ключ `"dashboard-attention-collapsed"`, значения `"1"` (свёрнуто) / `"0"` (развёрнуто).
- Тоггл вешается ТОЛЬКО на левый заголовок-кнопку. Ссылка «Все инсайты →» справа — отдельная, её onClick не трогаем (она навигирует).
- В заголовке показать счётчик `· {attention.length}`, чтобы в свёрнутом виде было видно число.
- Иконки: `ChevronRight` (свёрнуто) / `ChevronDown` (развёрнуто) из `lucide-react`.
- Внешний guard `attention.length > 0` НЕ трогаем: если сигналов нет — панель как и раньше не рендерится (сворачивать нечего).
- Чтение localStorage — в `useEffect`, не в инициализаторе `useState` (иначе hydration mismatch при SSR).

Состояние + persist + тоггл (добавь внутри `ModulesHome()`, после строки `const [me, setMe] = useState(...)` ~строка 76):
```tsx
const [attnCollapsed, setAttnCollapsed] = useState(true);

useEffect(() => {
  const v = localStorage.getItem("dashboard-attention-collapsed");
  if (v !== null) setAttnCollapsed(v === "1");
}, []);

const toggleAttn = () => {
  setAttnCollapsed((prev) => {
    const next = !prev;
    localStorage.setItem("dashboard-attention-collapsed", next ? "1" : "0");
    return next;
  });
};
```
Заголовок-кнопка — заменяет блок строк 141–144 (`<div className="mb-3 flex items-center justify-between"> ... </div>` с `<h2>Что требует внимания</h2>` и `<Link>Все инсайты →</Link>`):

<div className="mb-3 flex items-center justify-between">
  <button
    type="button"
    onClick={toggleAttn}
    className="flex items-center gap-1.5 text-xs font-bold uppercase tracking-wider text-gray-400 hover:text-gray-600"
  >
    {attnCollapsed ? <ChevronRight className="h-3.5 w-3.5" /> : <ChevronDown className="h-3.5 w-3.5" />}
    Что требует внимания

Условный рендер списка — блок `<div className="space-y-1"> ... </div>` (строки 145–158, содержит `{attention.map(...)}`) обернуть так, чтобы при свёрнутом состоянии список не рендерился (заголовок выше остаётся всегда):
