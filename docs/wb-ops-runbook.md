## Env (Vercel)
- `CRON_SECRET` — уже есть (крон-аутентификация).
- WB-токены — есть (`WB_STATS_TOKEN`, `WB_TOKEN_ADVERT`, `WB_TOKEN_CONTENT`).
- Гейты-выключатели (по умолчанию не заданы = фича в штатном режиме):
  - `ADVERT_DOCKING_OFF=1` — глобально стопнуть авто-докидывание.
  - `CTRTEST_OFF=1` — стопнуть оркестратор CTR-тестов.
  - `CTRTEST_PHOTO_SWAP_LIVE=1` — РАЗРЕШИТЬ реальную смену главного фото витрины (по умолчанию no-op). Включать только после живой валидации.

## Как пользоваться

**Репрайсер** (`/repricer`): «Прогнать сейчас» → таблица предложений (стратегия-точка, цена→новая, маржа/GMROI/ДРР, сигнал) → «Скачать XLSX» → залить в WB вручную (human-in-the-loop). Стратегии правятся в таблице `repricer_strategies` (или `POST /api/repricer/strategy`). gmroi — proxy-метрика, при странных значениях калибруется в `lib/repricer/run.ts`.

**Решатель цены** (`/price-solver`): на каждый SKU — текущая маржа и нужная цена под 15/25/35% + Δ. Кормит `margin_floor` репрайсера.

**Сигналы**: крон пишет «узкое место» каждого SKU в `agent_insights` (видно в `/agent`); также в колонке репрайсера. 46 SKU без себестоимости → нет сигнала по марже: заполни себес в `/costs`.

**Докидывание** (`/ad-docking`): добавь РК (advertId, кабинет, окна МСК, сумма, порог) → **Включить**. ⚠️ Включение = разрешение на авто-списание бюджета: крон в окне докинет сумму, если бюджет ниже порога, и релончит паузу. Лог — на той же странице. Стоп: `ADVERT_DOCKING_OFF=1` или выключить РК.

**CTR-тест**: пока СКЕЛЕТ. `POST /api/ctrtest/create` создаёт тест (enabled=false). Живой путь (смена фото витрины + создание тест-РК + замер показов по вариантам) НЕ валидирован — нужна совместная сессия и `CTRTEST_PHOTO_SWAP_LIVE=1` только после неё.

## Не сделано (нужен владелец)
- CTR живой путь — необратимая смена фото боевых карточек + траты на РК → отдельная супервизия.
- Headless-скрейп кабинета (РК/дневные метрики вне API) — нужен экспорт WB-сессии (`storageState`).
