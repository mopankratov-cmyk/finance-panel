2. Одна машина — два лица

Один движок, сверху два интерфейса: студия-админка для оператора и простой продукт для клиента. Одно действие — разная глубина.

  • рецепты, блоки, движки
  • ОТК-оси, веса рубрики, пороги
  • очередь, журнал сигналов
  • сырые метрики, подтверждение подсказок

3. Ноды — для админа, кнопка — для клиента

Нормальное видео = композиция из блоков (склейка, бит, текст, музыка). Кто соединяет блоки — ИИ (авто-монтаж) или оператор (вручную нодами). Клиент видит результат, а не граф.

Фото→ Генерация→ Нарезка→ Текст + стикеры→ Музыка→ ОТК→ видео
↓ граф сохраняется как рецепт ↓

4. Лестница глубины управления

Просто по умолчанию, глубже по запросу. Без точечной настройки человек не получит нужный результат — поэтому творческие ручки открыты по глубине; скрыто только техническое.
