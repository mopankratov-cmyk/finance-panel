Контент-завод · пилот 04.07

Контент из товарных твинов — Reels/Wibes + Pinterest

Пилот по итогам исследования: главный актив — цветовые линейки с идентичной геометрией (перекраска из эталона). Форматы №1 по данным: цветовой свитч-ролик (Wibes: досмотр + «пиши номер» в комменты) и палитра-пины (Pinterest: коллажи/палитры сохраняют в 2 раза чаще обычных пинов). Себестоимость пакета на модель ≈ $1, амортизируется на 8–9 SKU.

1 · Видео «9 цветов одной куртки» — формат №1 для Wibes

Хук 2с → 9 цветов по 1с с плашками → эндкард «пиши номер цвета в комментарии». Детерминированная склейка карточек (ноль AI-видео = ноль искажений), 11с, звук не нужен.

2 · Pinterest-пины 2:3 (1000×1500)

Палитра-грид — самый сохраняемый формат для одежды 2025–26. Каждый пин ведёт на карточку WB конкретного артикула с UTM (WB режет комиссию за внешний трафик). Сцена — nano-banana «замена только фона», куртка попиксельно нетронута.

3 · Kling-биты для silent test-drive (движения по вайтлисту)

Разрешённые движения: наезд, статичная камера + ветер, параллакс. Запрещённые: развороты/360°/морфы. Второй клип — живой пример, зачем нужен ОТК: Kling самовольно развернул куртку (выдуманная спина) → брак.
