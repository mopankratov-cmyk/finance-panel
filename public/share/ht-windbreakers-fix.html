Ветровки HT-42 / HT-80 / HT-83 — правки Андрея

Правки пришли из Telegram (чат NORVIA | WB). Каждая база отретуширована по описанию, затем перекрашена на все цвета модели — конструкция наследуется от одной проверенной базы, цвет меняется точечно. 24 твина (3 базы + 21 перекраска) через product-twin/recolor, 0 ошибок.

HT-80 · капюшон вместо воротника-стойки (получилось с первой попытки)

Правка Андрея: «В этой ветровке нет воротника отдельно, только капюшона, по аналогу худи» + длина тела −2см. Текстовое описание без референс-фото сработало убедительно — капюшон округлый, с кулиской, ровно как на фото Андрея.

Капюшон разошёлся на все 8 цветов модели без потерь — заодно закрыло старый баг «HT-80-01/02 без капюшона» для всей линейки, а не только этих двух цветов.

HT-42 · рукав +3см (утяжку пояса не осилили текстом)

Правка Андрея: рукава длиннее тела на 3см + чуть утянуть по поясу «как у св-зел». Рукав получился — манжета теперь ниже линии кармана. Утяжку по поясу нано-банан не сделал: без референс-фото описание оказалось слишком расплывчатым, силуэт остался прежним. Решено пропустить утяжку, не гнаться за ней текстом дальше.

HT-83 · без структурных правок

Андрей: «берём этот шоколад цвет за базу и делаем все остальные цвета по нему» — без доп. правок по крою. База уже была верной, просто разошлась на 7 цветов.
