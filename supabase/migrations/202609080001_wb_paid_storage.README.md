# Как применить эту миграцию

Нужно один раз выполнить SQL-файл `202609080001_wb_paid_storage.sql` в самой базе — мёрдж PR в `main` этого не делает автоматически.

1. Откройте [supabase.com/dashboard](https://supabase.com/dashboard) → проект финансовой панели.
2. В левом меню — **SQL Editor** → **New query**.
3. Откройте файл `supabase/migrations/202609080001_wb_paid_storage.sql` в этом репозитории, скопируйте всё содержимое.
4. Вставьте в SQL Editor и нажмите **Run**.
5. Должно появиться сообщение об успехе и создаться таблица `wb_paid_storage_rows` — проверить можно в **Table Editor** слева.

После этого ничего вручную запускать не нужно — крон сам подхватит новую таблицу в течение часа (задача `/api/sync/paid-storage`, раз в час) и начнёт заполнять её данными по «Платному хранению» WB, начиная с самой свежей недели.

Если что-то пошло не так при выполнении SQL (ошибка в SQL Editor) — ничего в проде не сломается: код в панели рассчитан на то, что таблицы ещё нет, и просто продолжит работать по-старому (см. `lib/opiu/paidStorage.ts`).
